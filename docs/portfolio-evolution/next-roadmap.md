## 候选：Equal-sharing / Partition Workshop（仅规格）

### 要回答的单一问题

在不增加新游戏、奖励经济或符号答题层的前提下，儿童能否通过直接分配和重组可见物件，理解“平均分”“每组多少”“组数”和简单单位分数之间的关系？

### 核心循环

1. 一个完整集合或整体出现在操作区。
2. 玩家拖动或用键盘把相同物件公平分入 2–6 个容器，或切分一个整体。
3. 每次操作同步显示：剩余、每组数量、组数、总量与相应等式/分数。
4. 不公平或有余数时，物件保持可操作，反馈指出“哪一组不同/还剩多少”并给一个下一动作。
5. 完成后允许重组为原整体、换一种等价分法、撤销、重置或返回地图。

### 为什么与现有五站不同

- Lab：数量/关系实验；Clock：旋转时间；Array：行列缩放；Target：卡片合并；Slider：离散 reel 选择。
- Equal-sharing 的核心输入是“逐件分配或整体切分”，直接承载除法、等组、余数、单位分数与等价重组。
