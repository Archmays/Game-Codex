# STEP04 · 冰雪奇缘：艾莎的冰雪游乐日

本轮交付第三盒 v0.5.0，入口 `?play=world-in-a-box&scene=frozen-elsa-playground`。原窗边与德累斯顿盒子保留；不恢复退役内容，不开始第四盒。角色为自制同人玩具，非官方作品。

## 实际玩法与制作

0/16 即有常驻艾莎及冰桥、冰场、飘雪。桥逐段生长，稳定后才能通行；收桥会先让整组雪橇或步行伙伴退到安全位置。雪橇可绕湖、去冰宫、暂停/继续、返回停车位，安娜可选乘坐。雪宝可滑圆圈/八字、停到场边、重组和走桥；门与吊灯是已拼装物件的局部玩法。完成16件仍可继续玩，不要求魔法或滑行次数。

16件为安娜、雪宝、克里斯托夫、斯文、阿伦黛尔城堡、小镇房屋、镇上路灯、雪松、雪橇、森林灯、冰宫台阶、左右冰柱、冰门、尖顶和吊灯。自由分组/顺序，上层件有固定承托。艾莎、固定背景、安全平台及魔法不计拼件。五角色有区别化脸、发型/辫子、服装或动物结构；安娜乘坐使用坐姿形变，角色世界根与局部动作分离。

可重建源为 `games/world-in-a-box/blender/build_frozen.py`、同目录 `.blend`；Blender 4.5.14 LTS仅用于制作。正式GLB、哈希、clip及逻辑根清单见 `public/assets/world-in-a-box/frozen/asset-manifest.json`。画面由实际Three运行截图记录，未用Blender渲染或概念图替代。静态同材质几何合并，120片雪粒子；实体冰不靠大面积透明遮掩结构。

新曲104.35秒，四段变化，钢琴、拨弦、少量高音键、轻弦层；另有13个独立效果/环境文件。生成器及许可区分见 [来源说明](step04-sources.md)。三通道、总静音、音量偏好沿用，重置保留配乐相位并清除对象声源。

独立 `family-games/world-in-a-box/frozen-elsa-playground-v1` 保存schemaVersion、16件集合、帮助及稳定桥/冰场状态。恢复时运动暂停在安全站位；不持久化Three对象、动作队列或家庭身份。备份清单登记后为52个已知键/51个可导出键。重置默认“继续玩”，Escape取消，确认仅清本盒并立即回读，存储失败有提示。

## 六顶帽复查：发现 → 改动 → 复验

| 视角 | 实际问题与修订 | 复验依据 |
|---|---|---|
| 白：事实 | 冰桥通行判定必须覆盖斯文和车尾；改为整组区间，桥未稳不可进入 | 状态反例、车上暂停收桥、乘员撤销 |
| 红：第一眼 | 裙子/披风与身份不能只靠名称；保留脸、辫子、褶裙、驯鹿角及雪宝胡萝卜 | 开场、角色、坡路实际游戏截图；未宣称孩子认可 |
| 黑：失败 | 冰门轴向、坡路斯文高度、坐姿披风穿桥；修正Y轴铰链、路线距离采样和坐姿形变 | 门开启、整组坡路截图与反向返程 |
| 黄：价值 | 魔法不能只是粒子；桥通行、冰场滑行与飘雪均可在零件为0时体验 | 八配置零拼件施法及完成后继续游玩 |
| 绿：可重玩 | 安娜可选、圆圈/八字与安全停止；撤雪宝不能等待无关已停车雪橇 | 三类乘员撤销、雪宝退场、单元反例 |
| 蓝：收束 | 移动端标签拥挤、快速第二次点击被拒、上层槽被山挡住 | 调整标签排布、移除粗略双击过滤、移动真实山体；实际触控/遮挡检查 |

独立按儿童入口、视觉/可达性、对抗生命周期三个角度检查共享原始证据；这是Codex复查，不是六位真人或Pro评审。首屏不设读题门槛，局部操作按对象显示；详细说明留在本报告。没有通过关闭实体遮挡或缩减核心玩法制造通过。

## 验证与证据

最终结果由 [验收数据](step04-evidence/acceptance.json) 汇总，同源标识见 [源码冻结](step04-evidence/source-freeze.json)。612项/49文件单元测试、TypeScript检查、生产构建及受影响目录/存档/交互静态契约通过。浏览器使用Windows Chrome隔离新上下文：全键盘1366×900、鼠标1440×900、模拟触屏360×800、390×844、800×360、844×390、768×1024、1024×768。模拟触屏不代表物理手机/平板。

输入矩阵从大厅键盘进入、完成16件、玩法、设置、重置、换盒和返回；没有填存档或强制focus代替输入。关键魔法按钮逐个滚动到可见区域，五个内部点命中且至少44×44 CSS px。横屏文档允许正常纵向滚动，不能把滚动出视口的另一个按钮误判为被实体遮挡。独立真实表面点击在浮动标签外的城堡槽完成拼装。真实标签后台检查关闭自动化焦点模拟后切换标签，返回后必须明确继续。

模型/保存测试包含柱位、坏数据、整组退场、雪宝撤销、后台暂停；浏览器覆盖中途重置、迟到GLB、存储故障、桥上暂停收桥、撤安娜/斯文/雪橇、无安娜乘车、模态冻结真实动画画面。旧盒回归涵盖窗/风、码头/风铃、车船/撤销、SLUB剖面、重置和声音入口。旧测试中直接读取异步动作首帧的竞争改为等待原定稳定后置条件；没有延长等待上限或降低成功状态。

原两盒55个保护文件按起点Git clean-filter blob及当前字节SHA核对，全部不变，见 [保护证明](step04-evidence/protection.json)。所有浏览器测试用隔离上下文，不操作家庭真实存档；旧键保留测试只用合成操作生成的状态。

音频实际执行三轮104.35秒循环、五轮三盒切换、各通道单开、总静音、重置相位和退出清声源。循环记录为真实时间，无加速；PCM/声源证据不等于听感试听。[带声音操作记录](step04-evidence/frozen-operation.webm) 仅Canvas 15fps及WebAudio输出分支，不含麦克风、扬声器录音或画布外控制栏；[三轮循环样本](step04-evidence/frozen-elsa-playground-three-loops.webm) 可回听。

性能数据记录资源字节、首屏实测时间、60帧分位数、draw calls、Three几何/纹理数量与音源数。Three对象计数是资源趋势代理，不是显卡显存字节测量；真实VRAM测量未完成。加载与帧时受本机并行验收负载影响，不当作设备性能承诺。
