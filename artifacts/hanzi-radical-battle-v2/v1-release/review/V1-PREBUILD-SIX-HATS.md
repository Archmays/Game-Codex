# V1 Pre-build Six Hats Review

## White hat — known facts and live baseline

- `HEAD` and `origin/main` are both `60cb7ffe3bbfe5936ca83577ac30f310f5933c91`; the branch is a fast-forward-safe starting point.
- The current playable route completes the deterministic four-character Golden Slice and retains the prior machine-ready boundary, but it has no real-child Second-Use evidence.
- The live desktop walkthrough reached camp, battle, composition, ability choice, both boss phases, spellbook, and completion.
- Current child-facing gaps are concrete: only four characters and one short route, a visible build seed, a four-entry spellbook, procedural placeholder-like scenery, no staged three-chapter repair, and no V1 resume/recovery surface.
- Theme C has 16 selected source-bound assets; eight meaning-magic illustrations remain to be generated.
- Pre-existing untracked STEP 07 artifacts are user-owned history and are outside the mutation/cleanup scope.

## Red hat — likely child and parent reactions

- The large characters and short actions already feel approachable, but the current world looks like a prototype rather than a finished storybook adventure.
- A child is likely to understand “put the two parts together”; they are less likely to understand a visible seed, review terminology, or a long settings explanation.
- A parent should be able to see version, privacy, progress, sound, reduced motion, reset, and local-only storage without exposing those controls in the core child flow.

## Black hat — risks to guard

- Position forms for 看 and 跑, nested enclosures for 园/回, two independent 木 instances for 林, and semi-enclosures for 包/风 can become visually or semantically misleading.
- Expanding a hard-coded four-encounter state machine can create parallel truth sources or break deterministic replay.
- A save migration that overwrites malformed or future-version data would be irreversible; backup, checksum, recovery, and future-version protection are required.
- Generated transparent art can have halos or inconsistent scale; each chosen image needs alpha, legibility, dimension, hash, and runtime-load checks.
- Modal DOM layers can leak input to Phaser; touch targets, keyboard focus, reduced-motion parity, and GitHub Pages relative paths are hard gates.

## Yellow hat — value to preserve and extend

- The existing deterministic simulation, gentle retry language, ability semantics, local-only save, and four accepted learning records are strong foundations.
- Three four-character adventures create a complete beginning–growth–repair arc without increasing the fixed 12-character learning load.
- Theme C can turn every learning action into a visible world repair, strengthening the connection between form, meaning, and story consequence.

## Green hat — bounded solutions

- Derive the compatibility Golden Slice from one 12-character V1 manifest; parameterize the existing simulation rather than duplicating it.
- Keep rule outcomes in the pure simulation and expose only rendering/input hooks to Phaser and DOM.
- Use a versioned runtime asset manifest that binds all 24 production assets to SHA-256 and semantic roles.
- Represent enclosure boards with nested slots and source/display glyph pairs so child-visible position forms stay correct while semantic auditing uses canonical components.
- Keep three abilities identical across chapters but report their distinct verified boss-state effects after every chapter.

## Blue hat — execution and freeze rule

1. Update authorization and machine-readable guardrails.
2. Establish one 12-character/three-adventure content source and validate hands before UI work.
3. Extend deterministic simulation, V1 save migration/recovery, audio/settings, and chapter reports.
4. Bind existing Theme C assets, generate/select the eight missing meaning images, then rebuild the world and overlays.
5. Route the hub card and launcher, run targeted tests, P1–P8, R1–R3, auto-repair at most three loops, and only then source-freeze.
6. Keep V1.1 ideas out of this release unless a current SEV-1/2/3 finding requires the change.
