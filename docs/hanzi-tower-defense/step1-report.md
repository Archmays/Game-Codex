## 语言与玩法依据

逐条核对汉典：[炎](https://www.zdic.net/hans/炎)为上下，[林](https://www.zdic.net/hans/林)、[沐](https://www.zdic.net/hans/沐)为左右；沐为氵旁木声。[火山](https://www.zdic.net/hans/火山)、[山林](https://www.zdic.net/hans/山林)保留完整双字及词序。氵标为非成字部件“三点水”，不伪造独立读音；魔法不解释为字源。九条字核均含来源、读音／部件名、简义及熟悉词。

固定靶场使用同样资源、30 秒、同有效射程、不死亡的单靶，运行实际攻击模型：

| 配方 | 前体分别部署合计伤害 | 合成后伤害 |
| --- | ---: | ---: |
| 火＋火→炎 | 600 | 800 |
| 木＋木→林 | 532 | 720 |
| 氵＋木→沐 | 386 | 600 |
| 火＋山→火山 | 630 | 945 |
| 山＋林→山林 | 1,050 | 1,470 |

控制另测：同一移动靶 10 秒，无塔走 400，氵＋木走 300.50，沐走 232.84。实际第一波同一火核，在前段／双弯中心／城门后段分别击败 4／7／1 只，说明塔位确实改变覆盖。12 个种子×两条竞争路线全部通关；不合成的对照构筑在第六波失败。120 个种子×六波掉落测试保证四类基础材料可达；开局即可合成，不必等待随机部件。

真实 Chromium 通过普通鼠标＋键盘完成“炎／山林”路线约 **5 分 39 秒**，触控完成“火山／林”路线约 **5 分 02 秒**，均击败 122 只、城门 16、零漏怪；未注入战斗状态或加速时间。

有限参考 [Ironhide 塔升级设计说明](https://www.ironhidegames.com/News/Details/487)及[官方玩法说明](https://support.ironhidegames.com/support/solutions/folders/4000041257)，采用射程覆盖与不同攻击作用，不复制关卡。新背景由图像工具生成；敌人和塔基取自 [Kenney Monster Builder](https://kenney.nl/assets/monster-builder-pack) 与 [Tower Defense](https://kenney.nl/assets/tower-defense-top-down) 的 CC0 素材。13 项运行资产及 SHA-256 见素材清单。
