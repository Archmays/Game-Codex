# Post-observation decision gate

This gate applies only after one authorized real local session validates against the exact STEP 04 schema and identity. A synthetic fixture, agent run, Playwright run, screenshot, test, build, or readiness ZIP cannot enter it.

## Interpretation order

1. Confirm privacy, schema, feedback, session, build, sequence, and evidence-kind validity.
2. Read technical facts without inferring a human state.
3. Read structured observation facts and intervention codes.
4. Read optional child choices without treating replay preference as learning.
5. Read privacy-checked parent notes and interpretation separately.
6. Record gaps, stopping context, and `ADULT_ANSWER_REQUIRED` as explicit risks.

One session cannot establish learning effectiveness, generalized usability, broad child acceptance, comparative preference, long-term retention, or population-level suitability.

## Allowed next decision

After human interpretation, the parent may select exactly one for a later explicitly authorized task:

- `PROMOTE`: only when the existing promotion gate's real behavior conditions are all supported; this permits only the next bounded Pilot, not the full Ink Forest.
- `REVISE`: identify one primary observed issue, the smallest changed-only revision, frozen unaffected identity, and another observation condition.
- `STOP_AND_RETHINK`: stop expansion when the adventure/core structure action is not independently understandable or safety/interest requires a broader rethink.

Incomplete or identity/privacy-invalid evidence is not a default decision. Record `NEEDS_VALID_OBSERVATION` and do not promote.

## STEP 04 technical boundary

The maximum technical state before a real session is:

```text
AUTHORIZED_CHILD_FIRST_USE_READY
```

At that point, real child observation, interpretation, default-world promotion, production sprite expansion, and full Ink Forest remain not started. The next allowed action is for the parent to run one authorized local session and return `STEP-04_CHILD_FIRST_USE_RETURN_TO_CHATGPT.zip`.

Never emit `PASS`, `FAIL`, `CHILD_PLAYTEST PASSED`, `CHILD ACCEPTED`, `LEARNING VALIDATED`, or `PROMOTED` as an automatic result of FINISH.
