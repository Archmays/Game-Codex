# Raw national-standard originals

The raw originals formerly stored in this directory were moved out of the Git current tree by `GAME-CODEX-PORTFOLIO-FOUNDATION-01` after byte-size and SHA-256 verification. Processed indexes, crosswalks, source ledgers, and runtime assets remain in their canonical project locations.

The external content-addressed archive preserves one object per unique SHA-256. Its `reports/archive-manifest.json` records every original repository path, byte size, hash, source-role reason, and canonical object path.
