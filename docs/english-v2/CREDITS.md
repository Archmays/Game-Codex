# Wordlight Island V2 credits and attribution

## Pronunciation data

Carnegie Mellon Pronouncing Dictionary (CMUdict), pinned Git commit `74790861f652b15e4ac49015a90074ad62a27690`.

CMUdict's repository states that use is unrestricted and requests acknowledgement. It also warns that the dictionary may contain errors and omissions. Wordlight Island retains the selected ARPABET records and does not claim that browser speech synthesis reproduces them exactly.

## Lexical sense data

Open English WordNet, 2025 edition, © Open English WordNet contributors, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Source: [en-word.net](https://en-word.net/).

Wordlight Island retains OEWN sense identifiers. Chinese glosses, short English child definitions, sentences, world-response copy, grapheme groupings and hints are project-authored.

## Visual assets

The 40 concrete/action word assets in `public/assets/english-world/words/` are original AI-generated illustrations created for this project with the OpenAI image-generation tool, then resized, converted and validated locally. They contain no real-child identity data. Four color visuals are CSS and four quantity visuals are DOM-rendered.
