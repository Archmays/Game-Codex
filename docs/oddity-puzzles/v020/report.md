# 奇物事务所 v0.2.0「看清再行动」

本轮保留三个房间、五种奇物、原始 GLB、合法路径和 v1 匿名存档，改为场景地标与对象短动作栏。取盒、接触、交接、按住开关只合并必要的普通走近；转灯、恢复门、连接门、穿门、选释放位仍由玩家决定。

机器验收：PASS_MACHINE。最终源码树 `39a5bd3a9500837bc3d95650eed3e034a70aed985a1f0bd4a1d9eb2a7c2d6710` 的 600 项测试、构建、八布局完整流程、生命周期与无更新读回通过。此前 `42def19…` 候选发现普通托盘误用落点分支；现已限制为临时选择态，并在八布局实际输入中证明普通点击只选择、不移动、不占历史。旧包身份仅作修订历史，不能替代最终包。离线启动、Git 和 Pages 各自的最终证据记录在本地 `handoffs/oddity-puzzles-v0.2.0-delivery.json`，不以本机通过代替线上部署。

## 实现

- 关键地标以图标、中文名、投影引线对应实物；脚印、操作方框、照片框和释放人形区分用途。额外站位可展开，查看和镜头切换不行动、不占历史。两个开关固定为 △ 三角、◇ 菱形。
- 默认只列 1–3 个相关动作；能力卡与场景对象调用同一操作。照片容量、持有者和接应员请求明确显示。临时选择态持续注明人物、工具、对象；不能误切施法者或把接应员指令变成玩家走路。
- 意图层只编排原 `model.apply`，每步复验。整条走近＋操作共用一个撤回快照；取消、撤回、重置、退出和失焦使旧动画、声音与回调失效。继续调查不会恢复已取消动作。
- 相机只在原坏门上显示恢复轮廓。NPC 放回照片会真正走回托盘；解除门锁后的“一起出去”仍逐人沿原合法路线走完。
- Classic 入口保留 `from=hub`，返回 Classic；独立入口返回主世界。仅调整实际依赖它的既有 hit-test，未放松断言或改其他游戏。

## 实际验证与边界

- 最终 `pnpm test`：48 文件、600 测试通过，其中本游戏原规则 17 项、意图及地标 10 项。包括替代开关顺序、两能力缺一不可、容量／归属／视线、逐步失效及整体撤回。
- 最终 `pnpm build` 通过；原资产锚点、碰撞和导航审计通过，三个 GLB 哈希未变。已有大 chunk 提示仍存在。
- 生命周期：真实鼠标按下后 Esc 不穿透；动画中 Z/Esc/重置；真实第二标签页失焦与继续；音乐／音效实际 PCM、取消后静音；隔离的 quota／损坏存档反馈；实际 v0.1 包玩出的存档在 v0.2 原字节读回。导入旧存档仅为兼容性测试，不计入通关。
- 补验原生 Space 只执行一次、reduced-motion 环境可操作、组合行动中返回大厅再进入不执行旧拿取。
- Classic 入口／返回生产构建 hit-test：desktop-1366、mobile-390 共 2 项通过。Portfolio、interaction-integrity、play-readiness 静态合同通过。
- 初始画面经语义接受后，同一构建重新载入进行逐字节截图比较；`visual-results.json` 记录无更新读回通过。
- 浏览器、离线包及远端交付结果由最终附表记录。没有实机触屏、真实儿童首次使用、乐趣、学习效果或长期记忆证据；不支持直接双击 `file://`。

## 证据身份和复现

`source-before.json` 与 `source-after.json` 使用仓库既有排序文件 SHA 算法，覆盖运行源、资产、工具／测试、构建配置及输入合同；文档证据不进入自身哈希。`charter.md` 保留修订前来源与范围。最终命令日志、实际输入与截图清单绑定同一源码树。

复现：`pnpm test`、`pnpm build`；将生产构建在本地 HTTP 提供，设置 `ODDITY_ORIGIN` 与 `ODDITY_OUTPUT`，运行 `tools/oddity-puzzles/browser-v020.mjs` 和 `lifecycle-v020.mjs`。生命周期旧存档测试另需保留的 v0.1 包位于 5177；原生 200% 使用隔离 Chrome 设置档案。输出不能写回历史 v0.1 接受文件。

离线交付使用已验收的 `dist` 原字节打包，自带 Node，无需安装或构建；完整解压后双击 `启动游戏大厅.cmd`。固定地址 127.0.0.1:5175，沿用原浏览器地址才能继续本机进度。ZIP 哈希和实际迁移启动结果见最终交付记录。
