# 字阵守城 / 字间行者 · v1.0 美术方向

## 字阵守城

有体积感的手绘微缩战场。深青松绿 #102f2d / #23483f，暖金 #e7c87c 只强调可行动、选择与结算；火橙、水青、木绿、岩沙色沿原核定义。环境低对比、塔体中对比、规范字铭牌高对比。统一正交俯视约 35°、看见前面和右侧，光从左上来，投影落向右下；运行纹理塔基锚点 (0.5,0.93)，怪物足底 (0.5,0.93)。怪物约塔高的一半；首领以宽披风、号角和头冠区分，禁止仅放大普通怪。

塔体暗棕轮廓 1–2 个运行像素，金边限于交互与共鸣。保留已接受的火山、山林原图，生产纹理另存。基础核有火炉/叶箭弩/水滴喷口/投石臂；进阶改变轮廓和实际动作，不改技能。森林分枝弩体现多目标；山林可见根岩；火山熔岩口体现范围爆发。共鸣增加装置结构而非整张染色。

环境仅边缘/地表笔触：青岚为松绿苔地与薄雾；双岔湾为青蓝湿地卵石；烽台为赭灰岩地与余烬。无烘焙路、塔位、文字、城门；道路与终点直接读取模型。装饰不得落进可操作轮廓。

## 字间行者

暖白墨纸 #faf5e9，浓墨 #27352f，朱红角色 #a44032，克制灯金 #c39235。汉字本身构成世界；不使用插画覆盖后贴字。四章只换轻纸色：米白、灯暖、灰青、桃灰。地形低饱和，物件细框，规则下划线，目标角标，落点虚边；角色圆环/方框和“正在走”文字共同说明控制权。

整字使用本机规范中文字体（Microsoft YaHei / PingFang SC / Noto Sans CJK SC），标题可用系统楷体，禁止生成汉字。标题 26–32、场景字随格 26–46、主体 14–16、辅助 12–13 px；小塔铭牌 20–24。场景笔画前不得叠纸纹。手持、桥下水、影注记分开定位。合字结束必须完整；三步照明按可绕角格图显示，不画穿墙直线。

## 状态与动作

主动作 48–56 px、必要目标至少 44 px；实体归属始终可读。选中实线、可搭配虚线，禁用有明确原因。120–220 ms 动作，不阻塞语义交易；真实伤害时刻给命中反馈，弹道只作残迹。减少动态保留状态；低性能减少装饰和粒子；静音可完整游玩。没有频闪、强制镜头或默认震动。

正例：塔的装置＋规范铭牌；暗影格“暗·不通”，亮格标步数；组合前显示实体和目标塔位。反例：随机视角/光源，彩色字牌充当所有塔，假透明黑底，地图假路，绘错字，森林无条件更强，灯光穿墙，动画结束才扣材料。
