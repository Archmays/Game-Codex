## 5–10 分钟非诱导观察

### 1. 自主开始

- [ ] 不读长说明也能找到可操作的滑轨、数字方块或箭头。
- [ ] 能识别中央黄色区域是当前算式。
- [ ] 能说出或用行为表示本关目标是什么。
- [ ] 若停顿，记录停顿位置和时长，不立即教操作。

### 2. 操作与反馈

- [ ] 能用拖动、相邻方块或箭头中的至少一种方式移动。
- [ ] 理解一次操作只移动一格。
- [ ] 没有把页面滚动误认为滑轨移动，或反复触发滚动冲突。
- [ ] 看见黄色点亮后，能理解“这次用过的数字已经点亮”。
- [ ] 算对一次但尚未完成时，能理解还要寻找其他组合。
- [ ] 错误后愿意继续尝试，且反馈没有造成压力或羞耻感。

### 3. 提示与语言

- [ ] 一级提示足以帮助儿童重新思考，而不是直接给答案。
- [ ] 二级提示中的“第几条滑轨”能被理解。
- [ ] 三级提示中的“向上/向下移动一格”能被准确执行。
- [ ] 记录儿童听不懂或误解的词：__________
- [ ] 记录最少需要的家长提示，以及发生时点：__________

### 4. 完成与继续

- [ ] 完成卡中的移动次数、提示次数和站区回顾能被理解。
- [ ] 能主动找到“下一关”或“再玩一次”。
- [ ] 愿意继续玩下一关；若不愿意，记录儿童原话或可观察原因。
- [ ] 5–10 分钟后没有明显疲劳、烦躁或重复机械操作；若有，记录出现时间。
