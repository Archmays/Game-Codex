# 世界盒子 STEP03-R2：前两盒精修

本轮只保留《窗边有风》8 件和《德累斯顿·河畔校园》18 件。实际配乐、互动声、模型和生成源均已落地；未完成实际听感确认，不把技术音轨检查当成试听。最终机器检查、源身份与交付状态分别见 `step03-evidence/verification.json`、`source-freeze.json` 和离线包旁的交付记录。

## 已复现、已修正

码头原始锚点 `[5.8, .42, -2]` 在默认相机中的屏幕位置为 `[554.94, 441.44]`。沿该射线先碰到南岸 `fixed_world_Ash / fine original grain`（距离 43.77），再到接口（45.43），因此原先不是简单的标签隐藏问题。保留原始 GLB 的计算回读以及修改前真实页面截图；调整码头实际甲板、接岸阶梯、系泊点与接口位置，并检查船壳侧向靠岸的间隙。没有关闭遮挡检测或增设穿墙点击。

穹顶、塔楼、采光顶补充可辨认的实体承接结构。提示现在先找实际可见射线，再验证最终 DOM 控件能被点击；被挡住会明确提示继续观察。所有物件仍可从正常分区视角与连续旋转中找到，帮助关闭时不会自动指答案。城市新增最近可见三维表面拾取，可直接点木模型或将托盘物件拖到表面；标签与实体共用语义动作。

两盒的左转、右转均为按住持续旋转，鼠标、触屏、Enter/Space 松开即停止，可以停在任意角度。取消、失焦、隐藏和打开模态框也会停止。跟随车船时选择物件或手动观察会退出跟随。修复负方向抵达时朝向反转，船沿河减速、对位后再侧向系泊，先离岸再继续沿河行驶；轮桨和水声跟随真实含侧向速度。车船近场面板显示目的地和操作。

删除吞掉不同目标连续输入的广泛过滤。窗边补齐 Z 撤销；同一鼠标双击仅接受一次，但紧接着的键盘操作可正常执行，持键重复由原生输入生命周期处理。撤销、重置和场景销毁会取消旧归位、照片及加载回调。

原生滚动通知可能晚于实际页面移动到达，原逻辑会误取消通知到达时刚开始的一次点击。两盒现在对比按下时记录的视口与祖先滚动容器位置：真正滚动仍取消手势，早先滚动的迟到通知不取消位置未变的新点击。轮滚、失焦和多指取消保留。

窗边一扇/两扇窗的风层次不同，帘、叶、书页、风铃错开变化；关窗后运动及相应声源真正停止。木猫短暂伸展后归位，杯子暖汽不累加。图书馆剖面保留采光顶和地下桌椅，退出恢复观察位置；六组本地实景对照和时钟继续保留。

## 重置与保存

两盒只有明确的“重置本关”破坏性操作，确认框默认“继续玩”，Escape 取消。确认清除当前拼装、历史、选中、托盘页、相机跟随、车船行程、剖面、照片、旧动作及物件声音；保留另一盒、其他游戏和声音偏好，同曲保持播放相位。存储写入后回读；失败显示“本次已重置，暂时无法保存”。

检查覆盖部分/全部拼装、归位中、风/暖汽、车船运动与靠岸、剖面、照片、取消与确认、刷新和晚到回调。所有测试使用隔离浏览器上下文及明确标识的故障夹具，不读取或清理家庭浏览器实际存档。旧 `v1` 和 `dresden-river-campus-v2` 保留；新增 `audio-v1` 已纳入备份登记（50 个已知键，49 个可导出键）。

## 音乐与互动声音

两首均为制作期 Python NumPy/SciPy 原创编配、模态乐器与种子噪声离线合成，没有调用在线音乐模型或第三方采样。`tools/world-in-a-box/render-audio.py` 可复现，实际 PCM WAV 为 24 kHz 双声道；作者、CC0-1.0、精确时长、SHA-256 和循环区间见 `public/assets/world-in-a-box/audio/manifest.json`。

| 主曲 | 时长与结构 | 乐器 |
| --- | --- | --- |
| 窗边有风 | 75.79 秒；76 BPM，3/4，32 小节，A/A 变化/B/A 回归 | 柔和模态钢琴、拨弦 |
| 河畔校园 | 91.43 秒；84 BPM，4/4，32 小节，同样有完整变化段 | 钢琴、拨弦、柔和笛/弦层 |

以下是清单对应的触发与停止约定。一次声只在接受有效动作后播放；加载/解锁前的旧动作不积压重播。

| 文件/声类 | 触发 | 停止或限制 |
| --- | --- | --- |
| pick | 选择尚未拼装物件 | 一次；不随焦点/悬停响 |
| place-light/medium/heavy | 成功归位，按物件轻重选择 | 一次；同一语义动作不重复 |
| undo、mismatch、complete | 有效撤销、形状不合、完成最后一件 | 温和短声；完成不替换主曲 |
| shutter | 已安装窗扇实际开合 | 一次木质声 |
| wind、chime、page | 有效开窗；风铃须已安装；书/植物须已安装 | 关窗、撤销、暂停、重置停止；风铃/细响有间隔 |
| cat、cup、steam | 木猫伸展、杯子轻碰与暖汽 | 短声；重置/撤销清除旧声 |
| boat-start | 新航程真正出发 | 柔和一次汽笛；暂停后继续不反复鸣笛 |
| boat | 实际沿河或侧向运动 | 随真实速度；暂停、系泊、撤销、重置停止 |
| boat-contact | 实际运动到停稳的转换 | 一次轻接触 |
| tram-start、tram、tram-stop、blocked | 实际起步、运动、到站或缺桥阻断 | 已在终点不假启动；阻断短提示一次，滚动声停止 |
| section | 玩具图书馆剖面开合 | 一次柔和模型移动声；近看压低外围声 |
| room、river | 对应场景的固定环境 | 低音量；隐藏/离开停止；重置允许保留 |

音乐/音效/环境三通道默认 25/55/15%，均可设置 0；保留总静音和旧静音意义。一个共享 AudioContext、场景自有声源、短声上限、同物件循环唯一、总线压缩与轻微配乐压低防累积。换盒子淡出旧声并自动淡入新曲；暂停记录音乐偏移，重置保持同一曲源。系统后台中断后车船保持安全暂停，需主动继续。退出后音源、RAF、加载回调及 WebGL 资源清理。

## 验证与证据边界

证据中的实际操作使用鼠标、触控和键盘输入。含桌面、360/390 手机竖屏、手机横屏、平板横竖屏、全部 26 件自主观察、真实表面点击与拖放，以及模态框/失焦/多指/快速操作等反例。断网、音频拒绝恢复、资源失败、保存失败仍可继续拼图。新上下文、空缓存、外站请求阻断下检查迁移后的本地 HTTP 包及 `/Game-Codex/` 子路径；不声称支持 `file://` 双击运行。

单元测试收集 573 项：整轮 572 项通过，一项未修改的旧游戏求解测试在并发负载下触及原 5 秒上限；原案例、原断言、原时限单独复跑用 2.291 秒通过。其后的局部输入修订重跑直接相关的输入合同与世界盒子模型检查，并复跑真实输入矩阵。城市靠岸检查曾在多个浏览器任务并行时触及原 9 秒上限；冻结静态构建后独立完整跑完七个配置通过，未改等待时限、模拟速度或断言来制造通过。共享入口命中矩阵、14 项入口烟测和三配置备份回读另有记录。

`audio.json` 记录音乐、音效、环境单独开启、总静音、关窗、保持音乐重置、车船状态声音、往返五轮与资源清理。`loops.json` 记录每首实际连续三轮、非加速的播放、接缝采样、无更换曲源与峰值检查。保留窗边操作和船出发→行驶→系泊两段短音轨，以及两段三轮主曲音轨。这些是实际 Web Audio 输出支路采集的 Opus/WebM，不是麦克风、扬声器或无声录屏。

Chrome 已实际解码全部 26 个 WAV。当前 Windows WebKit 构建未提供 OfflineAudioContext，相关解码检查记为不可用；模拟触控不等于物理 iPhone、静音键、扬声器或系统中断实测。**未完成实际听感确认**：数值峰值和非零波形不能证明乐句悦耳、混音舒适或听觉疲劳。实际音频功能已交付，可听录音随证据保留。没有声称儿童喜欢、教学效果或长期重玩得到验证。

独立视角反思：儿童操作检查关注是否可自主找到接口及取消；视觉/可达性检查关注真实遮挡、44px 目标、窄屏和剖面；对抗生命周期检查关注迟到回调、保存失败、后台、重复输入和声源泄漏。该过程发现并实际修订了码头几何、提示最终命中、交叉输入去重和切盒子声音衔接。未在初始使用中复现但补测的项目包括存储配额故障、音频拒绝解锁、延迟照片/模型与多指取消，不将这些描述成用户曾遇到的问题。
