# 字间行者 · 内容与规则

本游戏只将林的现代字形拆成左右两个木字部件，再合回完整林字。木是此处的部件，不将两枚木都称作部首。合成不裁切字体、不声称给出了古文字演变。其他场景字完整显示，不提供拆解教学。

内容定向规则：保留 `docs/hanzi-radical-battle-v2/CONTENT-RULES.md` 的简体字形、结构、语言、来源与跨字段严谨性；此冒险的胜利只看空间目标，不适用旧合字题的唯一解／手牌唯一答案门槛。相同实体没有隐藏白名单。`content.ts` 是本轮小型确定性场景清单，没有新建候选大字库。

2026-09-07 逐条查阅汉典：人 rén（独体、行人）、木 mù（独体、木头）、林 lín（左右、树林；左右木字部件）、不 bù（独体；不开、不吹中的否定）、家 jiā（上下、回家）、门 mén（独体、开门）、风 fēng（半包围、风吹）、水 shuǐ（独体、河水）、开 kāi（独体、开门）、吹 chuī（左右、风吹）、山 shān（独体、高山）、路 lù（左右、走路）。每条固定词境、场景、身份及对应字典 URL 在 `content.ts`。没有音频、读音判分或自动语音识别。本轮不教授其他结构的部件拆解。

第一次尝试的 Word Game 独立站和简体 Steam URL 无法访问，随后繁体官方产品页读取成功。有限阅读到此结束；未下载参考截图、音乐或关卡。所有运行时字形由本机简体字体栈渲染，没有 AI 图片文字。

风的完整约定先在第二房间说明：随有效动作处理，踏入就沿箭头走到下一格；目标不可走则整步无效。第三房间是水桥的材料分配，第四房间利用既有风向造成的单向路，运输两份材料必须先合为一件。第五房间可以停风再运木，也可以让风继续吹，先架左支流水桥、走到桥末拿回身后的木，再将两枚木移到家前。两种策略改变的是短句和桥梁位置，不是作者指定的移动顺序。

体验目标约 10–15 分钟，依靠观察、尝试和规划；熟悉解法的机器回放会快得多。没有计时门槛、等候奖励、战斗、题目判分或真人效果宣称。
