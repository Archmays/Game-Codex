## 开发者人工抽查

对每站取首关、中间关和末关，共 60 关做静态逐项抽查：

```text
每章样本：01, 05, 10, 11, 15, 20, 21, 25, 30, 31, 35, 40, 41, 45, 50
四章合计：60 关；每站 3 关。
```

抽查内容包括 mode、movable/fixed 理由、目标、初始状态、最短首次成功、有效 arrangement 数、scaffold、primary skill、误区、三级提示与回顾。结果：

- Chapter 1 保持 fixed `+`、1–20 数带和从部分—整体到四部分组成的递进；没有 0 或装饰性 operator reel。
- Chapter 2 的多目标、固定减法和真实 `+ / −` 选择分工清楚；站区目标从拿走/相差过渡到加减互逆和两步关系。
- Chapter 3 同时出现因数对、整除、乘除互逆、三因数和间隔加减复习；没有除零或非整除有效答案。
- Chapter 4 的等式右侧、多目标、4/5 reel 和跨章迁移确有结构变化，不是只换 target 或 ID。
- 60 个样本均能从初始状态到达首次成功，且有至少 3 个有效关系完成全 coverage。
