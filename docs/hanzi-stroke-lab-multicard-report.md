## 专门反思及修正

1. 已查看真实结果截图：每张卡都有完整 SVG 字形和独立动作，两个“天”不是选择按钮。
2. 手机两列保留字形与约 48px 操作，允许纵向滚动；不把四张卡强塞进一个视口。
3. 卡面仅保留播放、收藏、详情，避免复制整套逐笔工具；来源信息在详情里，多音/缺数据提示在卡面。
4. 独立揭示状态与正在播放状态分离；详情移动原 SVG，卡片保留静态完整字形，避免视觉重绘破坏进度。
5. 保险箱核对额外发现并修复旧页覆盖风险；过期 Worker 错误也按实例拦截。普通测试中的旧单字选择器与自动开详情假设改为等价的多卡/显式详情操作，保留原语义断言。
6. 平板旋转后 150% 缩放复现详情框关闭按钮越出视口，改为相对可视容器限高，并在 Chromium/WebKit 复验。精确笔内进度测试使用受控时钟，组队列、手写和主流程仍按真实浏览器输入执行。
