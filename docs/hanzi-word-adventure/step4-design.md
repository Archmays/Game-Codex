# 字间行者 STEP4 设计与实现边界

当前实现将三章各五间放在同一套纯规则中。首章 r1–r5 的布局、句子、材料与风向保持原样。新章可以直接选择；完成只检查走到出口，不检查作者操作序列。儿童体验问题是：一个完整的字既占据空间又改变可走通路时，目标、光照和一步撤销是否始终可理解？机器检查只回答规则和操作契约，不回答儿童乐趣或学习效果。

光从明所在格出发；手持明时从人格出发，沿上下左右相邻通格最多传播三步。山崖、固定短句、空字位和关闭的门挡光；可绕角，绕行也计步数。每个被照亮的影格同时显示“亮”和准确步数，暗格标“暗·不通”。显示、碰撞、提示、搜索和保存有效性都读这一纯函数。日、月只作为明的材料，不能独立发光。明与林一样占一件携带额度。所有变换先形成完整候选状态，再验证玩家落脚和风的落点；失光会让人所在影格非法时，整步拒绝，材料不消失。暗影中的实体不能被拿走或变换。

明按现代左右部件呈现，日在左、月在右；从哪枚开始拿都相同。拆明向左扩展时，日落在左边新格、月留在原格；向右扩展则日留原格、月落右边。它们保留各自的材料身份位。光魔法明确作为游戏规则，不冒充字源。

2026-09-08 定向核对 [日](https://www.zdic.net/hans/日)、[月](https://www.zdic.net/hans/月)、[明](https://www.zdic.net/hans/明)、[影](https://www.zdic.net/hans/影)：分别使用 rì／太阳、yuè／月亮、míng／明亮、yǐng／遮光形成的暗处这些限定义项；明为左右结构，日月为现代部件。完整字形继续使用系统中文字体，没有生成含字图片。有限设计参照读取了 [Baba Is You 官方介绍](https://hempuli.com/baba/) 的实体规则说明和 [A Monster’s Expedition 官方页](https://www.monsterexpedition.com/) 的开放谜题定位，仅用于复查机制可见性和探索空间，没有借用关卡、图像或代码。

## 操作与继续

世界容器是一个可退出的 Tab 区域：方向键／WASD 移动，Shift＋方向键移动查看位置，Space／E 主操作，X 拆，C 合，Z 撤销，Esc 取消。相邻的明确选择优先，否则主目标使用明示朝向，并另显示目标坐标；远格查看会明确标注。林、明或可合材料存在多种动作时，主操作打开小选择，不能自动猜谜底。按钮上的 Space／Enter 仅激活该按钮一次。拆分方向区左右键选择、Tab 到确认。方向按钮区使用共享 rovingGroup；焦点和 blur／hidden／pointercancel 清理使用共享 input 生命周期能力。

鼠标与触控点邻接空路走一步，点物件只查看，再按明确动作。持字时可点“选择落字处”，再点相邻格只选择位置、不移动，随后主操作确认。主操作最小52 CSS px、方向50 px，其他目标最小44 px。保留自然滚动、缩放和安全区。没有必需拖动或长按。

新保存键 `family-games/hanzi-word-adventure/v2` 的结构是 `{version:2, activeChapterId, chapters:{[chapterId]:Journey}, settings}`。Journey 同时保存稳定 chapterId、roomId 与经验证的数组索引，含完整世界及最多256步撤销。每章独立继续，继续菜单显示房名和roomId；新游戏选已有章会明确确认重置该章。旧v1字符串不改，只有v2不存在且v1有效才复制。迁移同时比较旧源与新键；坏／未来v2不被旧数据覆盖；迁移存储拒写仍能从已验证旧检查点在本页继续。普通写入使用挂载会话原文比较，保护跨页与Vault恢复。URL `chapter=homeward|lamplight|confluence` 只选择继续，不重置。切章用replaceState同步chapter参数、保留from及其他参数，不增加历史步数，避免从旧章链接进入后换章刷新却回到旧章。
