两处环境为 Action Park、Color & Number Pier。三类确定性规则承担六个语言情境；道路、颜色和数量真实参与状态，不是点词后播一次相同动画。没有实时物理引擎、奖励货币、计时得分或拼词门票。所有场景可直接探索，现场提供观察、定位、明确一步的提示；提示不替玩家执行。

`I` 明确指虚构故事角色，`can` 表能力。标题保留原目标句；“准备试一试／尚未执行”与“现在的场景／角色刚才展示”分开。重涂、改数量、重置后当前描述重新计算，已完成标记只表示历史上试过目标句。

独立 pilot 变式表仅有项目原创四句：`The shell is blue.`、`The boat is red.`、`One boat sails.`、`Two shells shine.`。未写入30句 canonical 语料，也未将 shell／boat／shine／sail 等支持词及屈折变成新拼读考点。单复数、sails／sail、shines／shine、大小写、对象指代与句意逐项核对。

## 拼词、保存与版本边界

旧V2先按已发布的字段顺序／投影校验 checksum，再迁移。投影只服务旧校验合同，完整旧JSON原字节一次性保存在 `migratedFromV2Raw`，顶层和设置扩展继续保留。未来版本／未知规则／坏JSON／checksum不符／不可能位置或数量／拒读拒写均只读。每次写入比较当前原字节与挂载时最后成功写入的身份；跨页、删除、坏档、未来档或 Vault 换档后，旧的V3内存不能覆盖新记录。

真实冻结V2生产客户端在读到V3后进入未来版只读，区域、任务、设置与词册操作未改V3字节。已经在升级前挂载的旧V2脚本无法由新版本追溯修补；切换版本前应关闭或刷新这些旧页面。回滚先导出并保全V3档，再正常 revert 本任务提交；旧代码只读新记录，不清档或重写历史。
