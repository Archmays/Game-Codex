If the gate later opens:

1. A parent stays nearby but does not teach the answer.
2. Open the child route and the local observation sheet only.
3. Observe one ordinary first encounter with no recording, screen capture, upload, or personal identifiers.
4. Follow every stop condition immediately.
5. Export `STEP-03_CHILD_FIRST_USE_OBSERVATION.json` locally and return it only through the explicit package workflow.

Technical readiness is not child acceptance. The game remains a parent-review candidate until real observation is authorized, completed, interpreted, and separately accepted.
