# STEP 02 ImageGen Seed Prompt Pack

状态：仅供家长审核视觉方向的 Level 3 种子提示词。STEP 02 不调用 ImageGen、不生成图片、不制作 spritesheet，也不把这些提示词或未来图像称为正式美术。

## 使用边界

- 三个方向使用同一核心 Pilot、同一角色关系、同一信息层级和同一可访问性要求；只比较材质、配色、光线和动效语气。
- 每个区块都是独立提示词。复制时保留首行“【ChatGPT image】”，不要把它替换为图内文字。
- 所有图像必须是原创游戏资产方向，不模仿、拼贴或复刻任何现有儿童游戏、动画、电影、绘本、角色或品牌。
- 所有角色服务于约 6 岁儿童的非恐怖冒险；无暴力武器、血液、惊吓表情、广告、UI 文案、汉字、拉丁字母、数字、Logo 或水印。
- 角色锚点：墨灵师是一个小小、勇敢、温和的儿童魔法师剪影，圆脸、短斗篷、毛笔形法杖但不持武器姿势；墨点精灵是无肢体或极短小肢体的水滴墨点伙伴；墨团怪是可爱、软圆、能被光温和驱散的墨团；营地灯为圆润纸灯罩和木质小灯柱。所有方向都保持这个关系，不复制任何第三方设计。
