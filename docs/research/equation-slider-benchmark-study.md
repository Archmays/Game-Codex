## 可采用的机制事实

多源一致支持以下抽象循环：

1. 棋盘由多列数字或运算符 tile 组成。
2. 玩家上下滑动列，改变中央横线上的表达式。
3. 表达式满足目标条件时，参与的 tile 获得变色或点亮反馈。
4. 普通关卡通常要求寻找不止一条正确算式，使要求覆盖的 tile 逐步被使用。
5. 公开资料稳定提到单目标、多目标、等式平衡和唯一解四类谜题。

Daily、Weekly、Viral 是内容组织方式，不是本项目必须复现的核心规则。公开资料也没有把倒计时、排名或付费提示证明为普通关卡不可缺少的部分。

## 事实与推断边界

以下结论是合理解释或本项目决定，不能写成竞品已公开确认的精确规则：

- “一次正确算式点亮中央线全部 tile”由官方的中央线/变色描述与第三方实玩共同支持，但官方没有逐字定义更新集合。
- Multi 可以确认有多个结果要求，但公开文案不足以确定目标是同时还是依次完成。
- OnlyOne 只能确认“只有一个解”，没有定义它是唯一静态排列、唯一有序路线，还是唯一最短路线。
- 循环滚动、吸附、拖动阈值、撤销粒度、键盘和可见按钮均属于本项目的可用性设计。
- 运算优先级、整除、除零、负数和分数规则均由本项目独立定义。
- 应用商店的内容年龄分级不能证明其教学有效性；本项目的 6–10 岁学习设计由自己的教育契约约束。

## 原创改编决定

- 玩家可见名称只使用“算式滑轨 / Equation Slider”，视觉主题为原创“数学轨道站”。
- 四条线路、二十个站区、灯牌地图、休息卡、学习回顾、徽章和儿童文案全部独立设计。
- 关卡由本仓库的确定性生成器构造并固定发布，不读取、推断或重建外部关卡库。
- 使用明确 token evaluator，不使用 `eval()` 或字符串执行。
- 以 tile 唯一 ID 记录覆盖；同值 tile 仍是不同学习操作对象。
- “唯一路线挑战”在本项目中精确定义为：忽略正确算式的执行顺序后，最少完整覆盖所需的 arrangement 集合只有一个。这个定义是原创规则，不声称等同于外部产品内部算法。
- 等式模式在首版采用“3 或 5 个可滑动列组成左式，右侧为固定的单数或短算式”的布局；左右都由同一 evaluator 计算，使可滑列仍为奇数且适合 360px 竖屏。
- 进度只保存在浏览器本地，不引入账号、分析、广告、支付、排行榜或联网学习记录。
