# 世界盒子 STEP01-R2 · 窗边有风

产品 `world-in-a-box`，场景 `window-breeze`，版本 **0.1.0**。本轮仅一个可玩样板。入口 `http://127.0.0.1:5175/?play=world-in-a-box`；项目原有家庭启动器保留。没有新建账户、模式、课程、收集系统或第二场景。

## 实现与视觉修订

先通过杯子、木猫、窗扇样件，再复用同一 Blender 函数制作整套场景，最后拆成恰好八个 `piece_*` 根节点。156 个网格不等于 156 个物件。底座、墙、窗框、桌、窗台、坐台、杆、挂钩及接口固定；所有 piece/slot/pivot/anchor 从同一 Blender 场景导出。

木杯有内外壁、圆润杯口、把手和茶面；猫使用连续雕刻轮廓、耳朵、刻线表情、脚掌和独立尾巴；窗扇有可见铰链及正确转轴。主要可见模型全部来自 GLB。Three.js 几何仅用于接影地面与暖汽小特效。没有背景图片伪装三维，也没有烘焙活动物件阴影。

本轮实际修改：

1. 首轮木纹条带过强，降低纹理对比；相机上沿太紧，增加留白与画面高度。
2. 使用柔化实时阴影；完成后收起空托盘，留下完整小世界与操作按钮。
3. 窗帘安装后曾挡住右窗扇操作锚点，改为露出的固定接口；已安装窗扇的操作锚点跟随枢轴。窗扇向外开，避开猫和桌面物件。
4. 手机盆栽/杯子接口的 44px 标签曾相交，加入可见接口标签避让与引线；射线遮挡仍先于标签生成，无法点穿墙壁。
5. 连续触控曾被过宽的双击保护挡住，收窄为提交/机关/撤销；取消使用有效释放令牌，迟到 click 不恢复已取消手势。
6. 风与窗扇采用真实时间衰减并明确归零，低帧率关窗也会停稳；风铃使用独立平滑音量通道。

来源：[Blender 4.5 LTS](https://www.blender.org/releases/4-5/)；[官方发布目录及校验文件](https://download.blender.org/release/Blender4.5/)。机器绝对路径仅在本地交付安装记录中保存，未写入公开报告。

- 固定种子 190926；原创木纹图像纹理与支持的 PBR 参数，纹理内嵌 GLB/源 blend。
- 游戏实际 `BoxScene`/GLTFLoader 路径检查了三件样品及完整场景；展示截图来自真实浏览器，不是 Blender 效果图。

## 操作与状态

三件一页托盘，可自由选择；选物件→点真实可见接口，或补充拖入；320ms 归位、木质落位声。左右窗扇可互换，安装时使用目标侧镜像模型并默认关闭。未装窗扇是清楚的木封板。错误位置保留选择、不扣分、不改镜头。

帮助开关与主动提示共用一个帮助功能，提示方向和接口而不代放。键盘 Tab 跨区、方向键/Home/End 区内导航、Enter/Space 确认、Escape 取消；归位后恢复托盘焦点。鼠标、触控、键盘进入同一语义动作。视角支持水平旋转、约束俯仰、缩放和复位。

风只由已安装且开启的窗扇派生，驱动已安装窗帘、风铃、叶片与书页。先开窗后装物件、换序、撤销唯一开启窗扇、刷新，均保持一致。杯子暖汽和猫摆尾只是陪伴反馈。八件完成后留在原场景；不开窗就没有风的叙事。

复用 `createLocalStorageStore('world-in-a-box')`，仅写 `family-games/world-in-a-box/v1`，保存匿名已放件、开窗、帮助、静音。刷新自动继续；重来有确认，只重置本游戏。撤销记录限本次进入后的手动放置。

## 验证记录

规范记录见 `evidence/browser-results.json`、`evidence/edge-results.json`、`evidence/verification.json` 与 `evidence/source-freeze.json`。源身份沿用仓库的“排序后逐文件 SHA-256 行再哈希”算法，范围明确为运行代码、模型源、运行资源、QA 工具/测试、构建配置及输入契约；报告和截图是输出，不参与自引用哈希。

真实 Chromium 浏览器，Windows x64。七组：1440×1000 键盘、1366×900 鼠标、390×844 和 360×800 触控、844×390 横屏、768×1024 与 1024×768 平板。触控为设备模拟，**没有物理手机实测**。

键盘从大厅出发完成八件拼装、相机、提示、错误放置、取消、撤销、开关窗、猫/杯子、重来与返回；测试没有脚本填入拼装状态，也没有测试强制 focus。其他组独立完成相同核心循环。检查 44px 下限、无目标按钮交叠、无横向溢出、外侧风铃不可从屋内点穿。

运动验证同时检查实际渲染终态和全画面像素：开窗必须产生超过 10 个色差大于 1/255 的像素；关窗等到风、窗扇、归位、暖汽与尾巴均停稳后，两帧之间不允许任何像素超过 1/255 色差。最初 PNG 字节全等检查遇到 WebGL 一档色值的栅格化波动，故改为量化比较；没有屏蔽区域，也没有忽略实际运动。每组原始像素统计写入浏览器记录。

额外检查：原生 pointer/touchCancel、多指、滚动、真正窗口失焦、双击、长按重复 Enter、拖入、归位动画中撤销与迟到回调、左右窗扇互换。浏览器自动焦点模拟关闭后才把跨窗口事件计为真实 blur。退出确认 AudioContext 关闭、RAF 取消、WebGL 上下文释放。基础存档重置前后，隔离测试中的旧游戏键保持字节不变。

外网阻断在浏览器请求层实施，保留本地 HTTP；新上下文实际启动与核心操作，不依赖浏览器旧缓存。静态包另测固定 origin 与 `/Game-Codex/` 子路径。不是操作系统断网试验；不声明支持 `file://` 双击。

按三个角度分别复核同一批操作和截图：儿童首屏有直接选择入口，错误不扣分、完成不强退；视觉与可达性保留真实三维遮挡、可见相机按钮、连续焦点和触控尺寸；对抗检查覆盖取消、重复提交、撤销、旧存档与资源释放。已发现问题与实际修订列于上文，未把机器通过等同于真人体验接受。
