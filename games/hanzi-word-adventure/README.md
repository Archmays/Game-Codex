# 字间行者 · 借字归途

## 游戏目标

`?play=hanzi-word-adventure`，五个连续房间的原创文字空间冒险。操纵完整的“人”字，借木、林和不改变回家的路。目标体验约 10–15 分钟，无强制计时、题目判分、战斗、账号或麦克风。

## 适合对象

可在需要时一起读字、观察和讨论路线的家庭玩家。机器证据不证明真人儿童乐趣、学习或留存。

## 玩法说明

- 字巷：拿开挡路的木，再将它放到断水处搭桥。
- 借一个不：从门不开取出不，门即打开；将不借给风吹，才能向下穿过风口。
- 林里有路：在宽处拆林为左右两枚木，分别架起连续两格水路。
- 先合再拆：两枚木先合成一件林，带过只能向右的风口；在另一岸拆开搭桥。
- 回家：可以停风运木，也可以保持风吹、先架左边的水路再回收木；两枚木最终都用在家前。

点字只查看，不会自动移动或远距搬运。方向键／WASD、大方向按钮逐步移动；Shift＋方向键查看；E 拿／放、X 拆、C 合、Z 撤销、Esc 取消。拆林先看两格预览，再确认。规则短句和绑定的门／风格会一起突出。手里最多带一个字从首屏就常显。回家后可再走一次归途。

## 涉及知识点

林为左右结构，左右两个木字部件；显示完整字形，不裁切字体、不虚构字源。有限的“不”在固定主谓短句中表示否定，改变它绑定的局部对象。逐字固定词境、读音、释义、字典来源及采用的设计参考见 [content-and-design.md](../../docs/hanzi-word-adventure/content-and-design.md)。没有作者唯一操作序列或指定合字答案门槛。

## 设备适配

Phaser Canvas 只绘制完整 Text 字形和轮廓；DOM 可访问透明格按钮与同源格坐标重合。既有简体字体栈，不增加字体包。字体就绪才创建画布，正尺寸 ResizeObserver／窗口 resize 同步高 DPI；销毁时断开。窄屏格子保持 44 CSS 像素，允许页面自然滚动。没有外部运行时资源、音频采集或请求。

## 接入方式

`rooms.ts` 定义小地图和明确绑定，`model.ts` 原子处理移动、碰撞、物件、拆合、风与胜利；Phaser 不决定规则。`solver.ts` 用有界 BFS 和精确有向步行可达区域生成实际动作，不查询作者答案。运行时在独立 Worker 中按当前状态请求三级提示，不自动执行；区分已经搜完的无解和达到搜索上限。

唯一存档键 `family-games/hanzi-word-adventure/v1`，保存当前房间稳定状态、最多 256 步撤销、已解锁房间和减少动态设置。刷新恢复当前状态和撤销。损坏／未来记录和另一个页面的改写不覆盖；本页仍可玩。旧游戏存档不读、不迁移、不清空。
