# Post Second-use Gate

## Technical readiness state

When and only when parent authorization ingest, routing, classic compatibility, canonical launcher, continuity gate, local observer/event plumbing, fixture dry-run, declared tests, rendered evidence, independent acceptance, Git delivery, and readiness packaging all succeed, STEP 06 may report:

```text
STEP 06 COMPLETE
DEFAULT_WORLD_ENTRY_PROMOTED_SECOND_USE_READY
```

That state means tooling is ready for a parent to run one later natural, separate second-use session. It does not mean a real child session occurred or passed.

## Required status boundary

```text
Current phase: DEFAULT_WORLD_ENTRY_PROMOTED_SECOND_USE_READY
Completed: STEP 05 parent default-world and second-use authorization ingested; default world promoted; classic hub preserved; canonical local origin established; second-use observer and tooling ready
Not started: real second-use session, second-use interpretation, replay-route pilot, remaining 8 characters, production art, full Ink Forest
Next allowed task: parent runs one natural separate second-use session using START_STEP_06_SECOND_USE_CHECK and returns STEP-06_SECOND_USE_RETURN_TO_CHATGPT.zip
Not allowed yet: SECOND_USE_PASSED, REPLAY_ROUTES_AUTHORIZED, REMAINING_8_CHARACTERS_VALIDATED, FULL_INK_FOREST_AUTHORIZED, LEARNING_VALIDATED
```

## FINISH interpretation boundary

`FINISH_STEP_06_SECOND_USE_CHECK` validates identity, evidence kind, canonical continuity, ordered sequence, derived-action parity, stop/privacy, and absence of PII/media/automatic decisions. Its summary keeps separate:

- technical facts: canonical origin, continuity, first action/destination, forest/spellbook/treasure route, full run, return to world, errors, and relative duration;
- human observations: world recognition, persistence notice, intervention, engagement, and well-being;
- explicit non-conclusions: long-term engagement, learning effectiveness, retention, remaining-eight readiness, full Ink Forest, and production-art preference.

It never outputs an automatic `PASS` or `FAIL`. A real return package must remain private and uncommitted.

## Promotion hold

After a real package returns, interpretation is a separate parent/human decision. Until then, do not claim `SECOND_USE_PASSED`, `LONG_TERM_ENGAGEMENT_VALIDATED`, `REPLAY_ROUTES_AUTHORIZED`, `REMAINING_8_CHARACTERS_VALIDATED`, `FULL_INK_FOREST_AUTHORIZED`, or `LEARNING_VALIDATED`.
