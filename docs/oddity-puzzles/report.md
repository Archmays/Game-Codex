## 开始使用

本机双击仓库根目录 `启动游戏大厅.cmd`，打开 `http://127.0.0.1:5175/` 的游戏大厅，可进入所有当前游戏；奇物事务所直达 `?play=oddity-puzzles`。根启动文件已实际执行并验证服务身份，不会重新安装或构建。

家庭离线包：`handoffs/oddity-puzzles-v0.1.0-offline.zip`，完整解压后双击包内同名启动文件。包内包含所有大厅游戏的生产网页、Node 运行环境和许可文件，断外网可运行。固定同一地址以保留浏览器存档；结束用包内停止命令。生产包已在另一目录解压并实际运行，未调用系统 Node、Vite、Blender、安装器或构建器。不支持普通双击 HTML / file://。源 blend 留在源码目录，不塞进运行包。

## 规则与资产

隔墙的灯：眼位透过封闭玻璃转灯，只开局部光区；绕不透明 L 形隔板取盒，人物与盒都回到出口才过关。坍塌之门：相机只恢复同一个门实体，走廊仍断；完整门接通小院后必须实际走过。照片接力：一位同伴被外部持片者收纳，经真实窄口送片，NPC 实际拿片并按请求释放；两人保持相隔较远的开关后门保持开启，全员到出口。空照片送入可取回，角色可换位，动作不锁成指定步骤。

统一布局同时生成导航、碰撞、视线与 Blender 模型；采用一次坐标转换。正式 GLB 与布局逐项核对通过，活动部件和眼位/手部/灯轴/门铰链/托盘/投递口锚点独立。三份 blend、生成脚本、GLB、同模型缩略图均保留。角色有衣形、颜色、行走和拿放动作。原创本地 32 秒轻音乐与五类音效可分别关闭。规则为本游戏冻结设定，人物、美术、情节和声音未复制剧集内容。

## 实际验证

- 灰盒同源几何先测，再生成 Blender 正式模型并重跑。最终 **47 个测试文件、590 项测试通过**，其中 17 项奇物规则测试覆盖两能力缺一不可、隔墙/窄口/屋顶地板绕过、空照片、重复收放、片中施法、归属、单开关、原件恢复、占位和坏门传送。
- **8 个真实输入配置均从首页完成三关**：桌面纯键盘、鼠标、触屏，390×844 手机触屏，768×1024 平板触屏、1024×768 平板键盘、1024×1366 平板鼠标、1366×1024 平板触屏。均完成三级提示、撤回、重置/取消、返回、存档重载、空照片取回；没有注入状态或程序聚焦代替通关。
- 14 项生命周期检查通过：混合输入、动画中撤回/重置、真实标签页失焦暂停及显式继续、六尺寸布局/可点击区域、声音 PCM 独立开关、保存失败/损坏反馈、世界盒子旧场景与 Dresden 入口/重载/存档隔离。故障注入只用于独立存储异常测试，没有用于解谜推进。
- Chrome 设置页面实际选 **200% 页面缩放**，读回有效宽度 720、DPR≈2、CSS zoom=1，完成第一关、提示、撤回、重置和返回；另测 CSS 200% 重排。所有配置未出现横向溢出。正式 GLB 的模型点击与地面移动另经实际指针验证。
- 全大厅生产冒烟 **16 项通过**；新入口的桌面/390 点击遮挡 **2 项通过**。目录、备份键、交互/滚动契约验证通过。世界盒子代码与资产未修改。
- 所有三关资源本地、按关加载；主页不预载 GLB，浏览器错误与外部资源请求均为零。真实渲染采样最高 **88872 三角面、89 draw calls**；桌面 DPR≤2、移动≤1.5。数字是预算检查，不代替视觉质量或硬件帧率实测。
