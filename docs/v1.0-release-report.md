# 字阵守城＋字间行者 v1.0.0

## 本次变化

两款游戏保留用户已肯定的玩法。字阵守城继续提供三图 22 波、六个三波短局、11 字核／7 配方／3 共鸣；字间行者继续提供四章 20 房。规则、材料、碰撞、光照、经济、关卡、存档和锁定依赖的 12 个保护文件与起点 `7dccc5067c6ac8c5237b97a9ff4dc1d281fbd92e` 字节一致；没有改谜底、伤害、掉落、速度参数或存档版本。

- **字阵守城**：深青松绿微缩战场，11 种字塔与 3 种共鸣装置、三种普通怪、独立首领及呼援姿态；保留已接受的火山／山林来源。三地图各有环境，实际道路、塔位与城门末点读取原模型。汉字及完整英文仍是规范字体。
- **字间行者**：暖纸、浓墨与朱红角色；四章轻纸色区别。搬放、拆合、灯光及双角色变化在原子交易后表现，下一次操作可立即更新旧动画，撤销恢复整个权威状态。圆环／方框、手持区与“正在走”共同区分角色。
- **操作与继续**：显著显示具体内容与继续状态；设置内提供音乐／音效独立音量、静音、减少动态、低性能及可跳过／重看的短引导。波次／城门／暂停／速度共用紧凑常驻战况栏；低高度恢复自然滚动，键盘组合确认保留战场与按钮。重置在明确进度管理中确认范围。保留 Space、X/C、Q、Z、H、原生按钮一次激活、实际列数导航和鼠标／触控点选替代。
- **声音与可靠性**：两首原创 32 秒主题及两段环境循环；两条音乐声部，沿用有界合成音效及重要提示优先。真实手势解锁，暂停／隐藏／退出停止或挂起，音频与贴图失败可静默继续并重试。Ogg 优先，不支持时使用 PCM WAV；首次加载不请求高清原图或其他地图。
- **版本与反馈**：产品版本统一来自 `packages/presentation/settings.ts`，与内部存档版本分离。旧试玩地址保留，新增正式标题、图标、更新说明、制作来源及含产品版本／内容 ID 的本机反馈。反馈不上传。新设置键 `family-games/presentation/v1` 独立保护坏值、未来值和跨页旧写入者；原进度键未变。

## 六顶帽复查后的实际修订

保留成功玩法与辨字任务；删除厚格背景、空组合／英文面板与无关闪烁。修正怪物地台、平板标题竖排、主按钮触控悬停低对比、初始城门错位及塔位编号压住城门。将塔防无 WebGL 专有依赖的绘制改为 Phaser Canvas，解决实际浏览器 `Framebuffer Unsupported` 启动失败。修正管理确认框延后 close 事件截获下一次操作、单行材料虚列导航、迟到播放与重复待完成请求。

Windows WebKit 的 MP3 进程崩溃在无游戏代码的最小页面也复现；PCM 备用格式独立测试 6/6，实际两款播放／音量／静音重载／HTTP 503 重试连续三轮 12/12。早期最小页因该运行时没有 AudioContext 的诊断错误单独记录，不作为格式结论。手机常用按钮恢复 48 px；静态图通过实际游戏设置开启减少动态，避免本机 Chromium 媒体模拟与实际查询不一致。动态录像还揭示滚动后战况离屏，已移动原生速度／暂停按钮到战况栏，并用十种浏览器／尺寸验证常驻、单次激活、焦点不被遮挡与低高度降级。最后另修正地面林拆字残影误从角色出发，以及手机双字铭牌换行遮挡装置；仅调整表现来源与铭牌排版，整字与模型不变。最终矩阵与录制在相关修订后重新验证。

线上候选截图终审还发现底部重复状态条遮住第 4 塔铭牌和第 8 塔位。真实线上操作和几何检查先复现失败，再移除该条，将布阵／暂停说明并入已有战况栏，保留敌人数与控制。另修正通用悬停色导致金色按钮按下后文字对比度降至约 1.61:1；实际鼠标／触控后的 4.5:1 检查通过。两项修正后重新封存并不更新复验视觉基线，发布门禁绑定修正后的新提交；没有把前一候选的功能通过当作最终视觉接受。

正式 production preview，普通 1×，单独运行；先采首屏约 3 秒，再以实际操作进入密集战斗采 20 秒，最后用真实设置启用低性能模式。低性能样本处于同波较后时间，不作受控帧率收益比较。

## 边界

机器验收证明所列技术、内容与输入合同，不证明真实儿童乐趣、学习效果或长期保持度；保留用户“两款很成功”的反馈。Windows 浏览器模拟不是实体手机／平板；实体设备、扬声器实际听感及长期使用未测试。当前 Windows WebKit 运行时不提供 WebAudio，合成动作音效静默降级，音乐 PCM 可播放；Chromium／Firefox 的音频接口可用。没有麦克风、云端处理、账号、后端、PWA 或 Service Worker。未来语音仍仅保留“明确授权后游戏期间持续监听，不逐次点击”的方向。
