# 奇物事务所 v0.2.0 · 看清再行动

## 接入方式

入口：`http://127.0.0.1:5175/?play=oddity-puzzles`。双击仓库根目录的 `启动游戏大厅.cmd`，会复用家庭启动器打开同一地址的首页；从“奇物事务所”进入。现有各游戏入口和存档仍在。本地开发依赖已安装的电脑无需再次安装或构建；独立离线生产包自带 Node 与已构建网页，不需要开发环境。

## 游戏目标

观察空间限制，组合两种能力，让调查员和任务物件平安到达出口。

## 适合对象

喜欢观察与尝试的家庭，支持亲子共玩。

## 玩法说明

三关依次为隔墙的灯、坍塌之门、照片接力。每关只有两种固定能力，不选装备、不跨关携带、无战斗、计时、死亡或评分。借鉴能力组合的思路，所有人物、房间、情节、美术和音乐均为本项目原创；以下是冻结的游戏版规则，不代表剧集全部设定。

- 扳指：佩戴者眼位的直视射程为10场景单位。玻璃透视，实体墙挡住；连续搬运每0.08单位检查视线，整个目标的扫掠尺寸检查碰撞。固定物件只能操作关节；别人的持有物须先实际放下。
- 台灯：房间内唯一固定灯座，三个方向档位。只有持续照到通道墙的局部才可通行；在房内可手调。移动期间暂停接受下一次动作，撤回/重置可立即取消动画。
- 照片：外部持片者接触另一人收纳，容量一人，不可自收。奇物留外面，普通衣物随角色。片中人不可操作。外部持片者在身旁足够空位释放。接应员仅按明确请求行动，能拿放照片、释放、移动及保持开关。空照片可由NPC放回托盘，再用扳指取回。
- 相机：预存快照只记录原门板、铰链与锁孔，不记录走廊、人、背包或异能。恢复原门，不复制，不等于撤回一步。
- 钥匙：持有者到完整门的锁孔旁选择已知安全小院，建立通道后还须走过门。

第三关两名调查员可切换；NPC不能切换成玩家。按住开关是一个持续状态，无须实际长按键；移动后松开。两开关同时保持后门锁永久解除，本关全员到出口才完成。顺序可以调整，错误动作不扣资源也不进入历史。

## 场景操作

点带脚印的地标直接走过去；点物件只选择，在短动作栏选择操作。取盒、交接和保持开关可明确选择“走近并…”，不会自动解决灯、门或能力条件。人物模型、头像和脚下形状对应：圆形蓝衣、三角橙衣、方形接应员。接应员只接受请求，不切换成玩家。

点台灯后选墙面；能手调也能用扳指时，先明确选工具。相机以原门局部轮廓预览，恢复、用钥匙连接、穿门仍是不同决定。点照片显示容量、归属和当前动作；扳指搬运直接选实物托盘。释放只显示持片者身旁可考虑的空位，仍校验占位、隔挡和尺寸。两开关以固定的“△ 三角 / ◇ 菱形”命名，解除门锁后可以主动选择“一起出去”，全部走完才显示完成。

选目标时提示持续显示谁、工具、对象和待选内容。鼠标悬停和键盘焦点预览真实路径；触屏从常驻地标认路，释放和搬运有不同轮廓，无须先预览再确认。Esc/取消、撤回、重置和失焦都会取消未完成步骤。空照片仍能请接应员放回并取回。

## 设备适配

键盘：Tab跨区域，方向键/Home/End选项，Enter/Space确认，Esc取消，Z撤回，Q切换当前关在外面的调查员。鼠标/触屏可点击全部按钮以及相机可见的模型目标/地面落脚点，无强制拖拽。提示由玩家主动逐次打开：观察→规则→下一步。失焦取消尚未完成的整条意图并还原现场、停止旧声音；返回后点“继续调查”，不会继续执行旧回调。本关重置须确认，只清本关现场、撤回和提示，保留其他关、解锁和声音偏好。

`model.ts` 是玩法状态唯一真源；意图开始前通过原规则预检，只补用户选定操作所需的普通路径；走近与操作逐步重新校验并动画展示，共用一个撤回快照。切人、焦点和镜头不占撤回。渲染不另立玩法规则。独立匿名键 `family-games/oddity-puzzles/v1` 已登记现有备份清单。拒绝损坏存档并明确提示；写入后读回，失败可见。没有账号或儿童身份数据。

`layout.json` 为模型、导航、墙体碰撞和视线共同来源；`tools/oddity-puzzles/author-layout.py` 可重建。Blender进口只做一次 `(x,y,z)→(x,-z,y)` 转换，标准 glTF 导出为Y-up。模型脚本：`blender/build.py`，源文件：`blender/room-{1,2,3}.blend`，运行资产：`public/assets/oddity-puzzles/room-{1,2,3}.glb`。用 Blender 4.5 LTS 后台运行脚本重建；普通运行不调用 Blender。

正式模型包含倒角房间、五种奇物、档案盒、托盘、开关、门状态、衣形与颜色区分的三名角色。命名锚点包括眼位/手部、灯转轴/光源、门铰链/锁孔、托盘、投递口内外。静态同材质部件合并，关节和互动实体独立。能力卡缩略图和照片人像由同一正式Blender模型离线渲染为192像素本地PNG。近侧墙仅视觉剖面，逻辑墙仍参与检测。

原创32秒轻柔循环乐曲和5类短音效由 `tools/oddity-puzzles/audio.py` 制作期合成，本地PCM WAV播放。音乐/音效分别开关，失焦、撤回、重置、退出取消旧声音。没有CDN、在线字体、远程解码器或在线服务。

生产包使用HTTP启动，不支持普通双击HTML / `file://`。源blend不放入运行包。本轮验收证据与实际未测边界见 `docs/oddity-puzzles/v020/report.md`；v0.1.0 历史证据仍在 `docs/oddity-puzzles/report.md`；机器检查不能证明真实儿童喜欢、掌握或学习有效。
