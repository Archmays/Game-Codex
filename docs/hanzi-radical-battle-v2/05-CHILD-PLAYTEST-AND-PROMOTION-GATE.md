# 儿童试玩与扩建门禁

本门禁用于黄金样板完成后的真实试玩。自动测试、agent 试玩、成人代玩、浏览器截图和构建通过均不能替代黄小越的观察结果，也不能直接产生 `PROMOTE`。

## 试玩前技术条件

缺少任一项时只修复技术问题，不进入儿童结论：

- 防偏航测试和相关单元测试通过；
- 真实浏览器及至少一个代表性触控设备可完成全流程；
- 手机竖屏、平板横屏或实际使用布局无阻断；
- 首屏、第一手牌、成功合字、无效组合、三选一、小首领、营地修复、魔法书、撤退和减少动画有身份明确的截图证据；
- 本地存档可重载和清除，无账号、网络记录或云端儿童追踪；
- 12 字 manifest 已通过自动一致性检查和成人逐字内容/适龄审核。

## 试玩安排

- 一次 8–15 分钟以内：先让孩子独立探索黄金样板，再进行最多两三个中性回顾问题。
- 使用孩子平常会用的设备、音量和坐姿；先说明“这是游戏还在试做，你帮我看看哪里不清楚”，避免“考试”暗示。
- 一名成人观察、一名成人最多只在安全或明显卡住时提供预定等级的提示；不要边玩边教学。
- 不录音、录像或上传数据，除非家长另行明确同意。默认只记录最少匿名观察和本地相对事件。

## 核心观察问题

1. 是否愿意主动进入墨迹森林？
2. 是否能理解第一步该点什么？
3. 是否理解部件需要进入相应空间位置？
4. 第一次施法时是否出现可观察的关注、惊喜、停看、复述或主动操作？
5. 是否理解三选一，并知道自己的选择改变了什么？
6. 是否注意到营地永久变化？
7. 结束后是否主动想再试、换能力或查看魔法书？
8. 哪个环节开始失去兴趣、反复乱点或转向成人？
9. 是否需要家长不断代读、解释或替她操作？

## 优先观察，不只问“好不好玩”

不要把礼貌回答当结论。优先记录：

- 她下一步自己点了哪里，以及在第几秒开始行动；
- 提示前后行为是否发生变化；
- 是否把部件拖/点到真实结构位置，还是只是在猜答案卡；
- 第一次成字后是否看完整字、读音、词或怪物/世界变化；
- 是否能指出自己选的能力，并在小首领战中认出它；
- 是否主动指出营地哪里变了；
- 是否要求继续、想换能力/英雄，或主动打开魔法书；
- 是否主动复述某个汉字、熟悉词、怪物或世界变化。

可以在结束后中性询问：“刚才你做了什么魔法？”“你选的这个会怎样？”“营地哪里变了？”不要提示正确答案，不问“你学会了吗”。

## 唯一允许的结论

### `PROMOTE`

仅当下列证据同时成立：技术条件完整；黄小越能在少量提示下完成第一次合字；行为显示她理解部件位置而非只猜题；能理解至少一次选择；主动注意营地永久变化；未出现操纵/羞辱/明显不适；观察支持继续扩建。`PROMOTE` 只允许进入下一次明确授权的 Pilot 范围，不自动授权完整墨迹森林。

### `REVISE`

核心幻想或合字动作仍有吸引力，但入口、结构槽、提示、节奏、选择、反馈、适龄字或设备布局出现可定位问题。记录一个主要问题、最小修改和再次试玩条件；不要用更多奖励或内容掩盖理解问题。

### `STOP_AND_RETHINK`

孩子持续把体验理解为练习/答题；合字只有成人解释后才成立；结构学习与游戏动作分离；关键兴趣依赖禁用压力机制；或修复需要超出黄金样板的大系统。停止扩建，保留证据，重新讨论核心动作或幻想。

不得使用 `PASS`、`技术完成`、`孩子应该会喜欢` 或 agent 推测替代上述三态。若观察不完整，结论是 `REVISE` 并补足证据，不是默认 `PROMOTE`。
