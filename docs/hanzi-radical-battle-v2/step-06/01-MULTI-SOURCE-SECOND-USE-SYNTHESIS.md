## Child and Hanzi value

Default entry lets the child return directly to the accepted persistent world, while the explicit classic route preserves family access to all existing games. The continuity gate makes the repaired camp and four discovered characters genuine consequences of the prior run, rather than a staged display. The second-use check asks only whether the child recognizes the world, chooses any destination, and returns naturally; it does not quiz character knowledge.

Technical events establish actual actions only. Parent expectations, stated intent, and manually recorded observations remain separate evidence. One re-entry cannot establish learning effectiveness, retention, generalized usability, long-term engagement, or readiness for the remaining eight characters.
