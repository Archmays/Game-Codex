# 汉字魔法战 V2 北极星

机器可读约束以同目录的 `00-NORTH-STAR.json` 为唯一真源。当前状态是 `V2_CHAPTER_ONE_IMPLEMENTATION_AUTHORIZED`：精确授权 `HUMAN_AUTHORIZED_CONTINUOUS_V1_TO_V2_CHAPTER_ONE_20260813` 允许从已冻结的 V1.0.0 连续实现、机审并发布第一章 V2.0.0。机器通过不等于儿童乐趣、学习效果、偏好、保持或 Second-Use 通过。

## 玩家与体验承诺

核心玩家是约 6 岁、刚进入小学阶段的黄小越。第一眼应是墨迹森林、英雄、墨点精灵、怪物、选择、魔法和能被修复的世界，而不是课程目录。学习目标、适合年龄、正确率、错题、练习次数和成人说明只进入独立家长区。

## 游戏幻想与核心动作

墨迹森林正在褪色。玩家是能听懂字灵的汉字魔法师，与墨点精灵把散开的汉字部件放回真实结构位置。完整汉字形成后，同步显出读音、熟悉词和短义，再化为对应魔法，赶走墨怪并永久修复营地。

不可替换的核心是：**部件进入正确结构位置并组成完整汉字，这个动作本身就是施法。** 部件顺序、空间位置、字形、读音、词义与插图必须一致。怪物行为、英雄能力和局内选择只能改变操作环境、提示、资源或节奏，不能改变汉字的正确结构和答案。

## 第一章 V2.0.0 范围

第一章包含 36 个正式可玩汉字、3 位英雄、3 个区域与 1 个最终字核、9 种怪物行为、18 项可选能力、3 项英雄固有能力、8 项营地修复和 36 页魔法书。故事局目标 10–14 分钟；完成一次故事局即可看到章节结尾，不要求先收集 36 字。自由冒险在同一受约束、可复现的 seed 系统中提供路线、遭遇和能力变化。

旧 12 字、三段冒险和 24 项素材是 V1.0.0 的历史冻结范围，不再是 V2 第一章的扩建上限。V1 由 tag `hanzi-magic-v2-v1.0.0` 固定在 commit `43e7841d2190922b6048182cab4b871c55715840`，旧路由继续兼容。

## 为什么孩子会想继续

持续兴趣来自可理解的掌握、真正不同的路线和能力选择、英雄差异、每局小变化、新字进入自己的魔法书，以及营地的永久修复。结束时留下“下次想试另一位英雄或另一条路”的方向，不利用登录天数、排名、损失厌恶或限时奖励施压。

## 技术与存档方向

运行时锁定为 Vite + TypeScript + Phaser 3 + DOM overlay + localStorage + GitHub Pages。Phaser 负责世界、角色、战斗编排和视觉特效；可保存规则状态独立于精灵、补间和 Scene 生命周期。文字密集的魔法书、设置、家长信息与可访问性控件使用 DOM overlay。

V2 使用新的带整数版本、checksum、backup、recovery 和 future-version read-only 的本地 schema。首次迁移前保留 V1 原始字节；保存 36 字发现、8 修复、英雄、设置、当前 run、已见能力和最小匿名事件；不保存姓名、生日、语音、照片、自由文本、IP、设备指纹或网络身份。

## 健康边界

禁止连续登录奖励、不登录损失、每日强制任务、无限抽卡、付费概率宝箱、排行榜、全球比较、连胜压力、失败惩罚性资源损失、FOMO 计时器和羞辱性失败语言。失败或撤退保留已获得的发现与永久进度。声音可关闭，静音仍能理解状态；非必要摇晃、闪烁和动画支持减少动画。

M0–M5 必须逐阶段 `PASS_STAGE`。最终至少验证 30,000 个确定性 simulation seeds、18 次真实浏览器机器通关、36 字来源与唯一解手牌、全部英雄/能力/行为/首领/修复覆盖、V1→V2 存档迁移和恢复、触控/键盘/静音/减少动画/响应式几何、V1 旧路由、经典大厅、构建与 GitHub Pages canonical route。任何未解决的 SEV_1–3 均阻断发布。

本次明确授权更新现有 GitHub Pages、commit、push 和 tag。它不授权后端、账号、儿童云追踪、Godot 迁移、操纵性留存、超出第一章的开放世界，也不授权把机器证据冒充真人儿童证据。

## 停止或收缩条件

出现以下任一情况即停止相关子改动并保留其他正常成果：真实结构被动画遮蔽；汉字内容无法由正式来源与本地母库支撑；手牌有多解或无解；seed 形成软锁或必败；新功能缺少 traceability 与自动/机器实玩路径；超出 36 字、3 区域加最终字核、18 可选能力或 8 修复而无新授权；出现禁用机制、第二种局外货币、后端、Godot 或儿童远程追踪。
