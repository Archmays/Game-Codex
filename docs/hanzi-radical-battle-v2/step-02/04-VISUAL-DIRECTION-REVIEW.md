# STEP 02 视觉方向审核

## 审核对象，不是最终美术

当前 A/B/C 都是同一核心 Pilot 的程序化审核方向：相同营地、同一位墨灵师、同一个墨点、同一团迷墨、同一结构槽和同一信息层级。比较时只改变配色、纸感和气质，不替换规则，也不生产最终精灵、动画条或品牌资产。

每个方向在数据中都标为：

```text
procedural-review-direction-only
```

家长可选择 A、B、C、`MIX` 或 `REDO`。选择只为后续讨论提供方向，不是对任何正式资产、STEP 03 或儿童试玩的授权。

## A / B / C 对照

| 方向 | 名称 | 当前气质 | 家长应看什么 |
| --- | --- | --- | --- |
| A | 暖墨绘本 | 米白纸张、柔和水彩、温暖珊瑚与青绿色圆润角色；强调安全、亲近、归家和修复 | 第一次进入是否像温暖的魔法冒险，而非练习页或紧张战斗？ |
| B | 剪纸字灵 | 分层剪纸、清晰阴影、高轮廓和不过饱和的纸片触感 | 可操作层级是否更清楚，同时仍保留柔和世界感？ |
| C | 夜光墨林 | 深蓝绿森林、柔和荧光、克制星点与高对比汉字区域 | 魔法感是否更强，又不会盖过结构信息或变得阴森？ |

三者都应保持：圆润、低刺激、可修复的墨迹、非恐怖的迷墨、完整字优先于粒子或镜头效果，以及静音时仍能看懂状态变化。

## 审核时的限制

- 不把截图或程序化色块当作最终生产美术质量。
- 不把现有本地视觉提示图片当字源、历史构形或儿童适龄证明。
- 不因为某个方向看起来更“酷”而牺牲槽位位置、完整字、短句可读性或减少动态分支。
- 不生成或批准能力卡、Boss、武器、稀有度、货币、抽卡、排名或其他未来系统。
- 不把 A/B/C 的选择解释为家长已同意候选字、核心玩法或 STEP 03。

## 审核动作

1. 在 review URL 的 Pilot tab 完成同一条“明”闭环。
2. 打开设置中的“审核视觉方向”，分别查看 A/B/C 对营地、迷墨、完整字和灯修复的影响。
3. 在视觉方向 tab 作一次正式选择，并在需要时写明 MIX 的组成或 REDO 的问题。
4. 返回核心 Pilot 检查选择后的视觉是否仍让“部件 → 成字 → 法术 → 世界变化”比背景更明显。

## 与 ImageGen seed prompt pack 的关系

`03-IMAGEGEN-SEED-PROMPT-PACK.md` 是未来 seed frame 的详细提示词包，不是本步骤开始批量制图的命令。只有一个后续任务在获得明确范围授权后，才可把已选方向转入小规模资产验证；仍需单独验证透明边缘、缩放、槽位文字对比、静音和减少动态。

## 当前结论边界

当前技术状态仍为 `CORE_SPELL_PILOT_READY_FOR_PARENT_REVIEW`。没有家长选择记录时，A/B/C 都只是待比较的方向；没有真实儿童观察时，任何方向都不能被称为“孩子会喜欢”。
