# 汉字书房

## 工具目标

直接查阅汉字、在本机手写找字、播放实际笔顺并逐笔定位。独立工具 ID：`hanzi-stroke-lab`，不计入三个主游戏。

## 适合对象

需要查字的儿童与成人。不会读的字可手写查询，没有分数、关卡或强制练写。

## 使用说明

- 输入最多 48 个 Unicode 字符；每个汉字按出现位置生成完整字卡，保留重复。例如“天天向上”直接显示四张卡。非汉字过滤、输入超限与缺数据提示均可见，未知字保留原字。
- 查询后静态呈现。每卡独立播放/暂停、收藏与逐笔详情；同一时刻只播放一个字。组级依次播放按出现顺序经过重复字，缺数据会提示并跳过；单卡播放退出组队列。“重播这个字”与“全组重播”范围分明。
- 逐笔详情按需打开，关闭或 Esc 恢复原卡焦点和滚动位置。码点、完整字音来源、简繁映射放在“字形与来源”，多音字与缺数据提示直接显示。
- 手写按需展开，接受鼠标、触摸、笔。停笔后本地 Worker 内的 `hanzi_lookup` WASM 产生最多十个候选。选候选后“查看这个字”只开预览，不改查询组；“加入这组”才追加。可继续写下一个。
- 切区保留完整笔迹对应的有效候选，未完成识别在返回时重新运行；“重新识别”和引擎重载均处理现有笔迹。撤销、清空与离开阻止过期返回覆盖当前笔迹。
- 最近查看最多 24 个、收藏最多 128 个，只使用原 `family-games/hanzi-stroke-lab/v1`。不保存轨迹、动画或队列。清空最近/收藏需确认。未来版本、损坏记录，以及页面打开后被保险箱/另一页恢复的原文都不覆盖；检测到更新提示刷新。
- 田字格开关不改变笔内进度或播放状态；暂停与继续保留局部揭示。画布保留固定定位参考线。

## 数据与边界

9,574 个字形条目有笔顺，含少量部件；9,507 个识别候选；67 个笔顺字不在识别模型中，候选缺笔顺为 0。12 个部件未收录独立读音。完整集合/差集见 `public/hanzi-stroke-lab/coverage.json`。

字音优先 Unihan 17.0 `kTGHZ2013`，其次 `kXHC1983`，否则 `kMandarin`。不进行语境消歧，不宣称穷尽读音。简繁字形不转换。来源、许可证和复现命令见 [SOURCES.md](../../public/hanzi-stroke-lab/SOURCES.md)。

识别限制以独立合成轨迹实测为准，不保证每次候选包含目标字。实际儿童识别准确率、乐趣、学习效果与长期体验均为 `NOT_CLAIMED`。

## 设备适配

桌面四列，窄桌面/横向平板三列，768px 和 360/390px 手机两列；长结果自然纵向滚动。Tab 跨区，字卡区域一个 Tab 入口；方向键/Home/End 换卡，Enter/Space 打开详情，详情中原生按钮完成所有动作，Esc 关闭。常用字、最近、收藏和候选也采用区域导航。键盘画笔说明按需展开，方向键移动、Space 落笔/抬笔、Esc 取消并退出、Tab 离开。触摸证据为浏览器模拟，不代表真机或儿童试玩。

## 接入方式

- 首页中文工具入口或 `?play=hanzi-stroke-lab`；query-only 导航支持项目子路径。
- URL `q` 保留原输入（含过滤提示），`i` 是过滤后的汉字出现位置，从 0 开始。旧 `q/i` 链接直接显示整组；`detail=1` 恢复详情开合，手写预览另用 `hand` 保存单字且不改 `q/i`。动画与笔迹不通过 URL 持久化。
- 字形请求按汉字去重并缓存；卡片身份、SVG 遮罩、焦点和进度按出现位置隔离。静态结果不创建动画实例或逐笔缩略图，详情关闭释放缩略图，退出清理 Worker、请求、帧调度和监听。
- 继续使用 `tools/my-game-world/START_MY_GAME_WORLD.cmd`，固定 `http://127.0.0.1:5175/`。
- 字库索引、Worker/WASM 和每字 JSON 从同源加载，无外部 CDN、API、账号、后端或 Service Worker。首页只包含轻量定义，运行时代码按路由载入。
- 当前 DOM、SVG 坐标和路径均为矢量，不依赖位图缩放，缩放、DPR 和旋转不清空已完成轨迹。未完成指针笔画取消后不提交。
