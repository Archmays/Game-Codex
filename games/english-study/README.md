# 英语书房

独立英语查阅与书写示范工具，入口 `?play=english-study`，也可从“我的游戏世界”进入。不恢复已退役的英语世界，不计入活跃游戏产品。

## 使用流程

输入一个或多个词后，每个词各有一张词卡，重复词保留。打开词卡，简明词义与整词四线三格书写板首先可见；按一次“播放书写”，同一张纸上的字母依次逐笔写成完整单词，已写好的部分一直保留。淡色范字可隐藏。手机上的长词同时有完整总览和可横向滚动的放大板，两处共享同一进度；视口变化不重置进度。

主控制为播放／暂停／继续、重播、上一笔、下一笔、完整字形和慢速／标准／较快三档速度。默认标准、不自动播放。暂停保留半笔；继续原位前进；下一笔完成当前笔后停住；上一笔先撤回半笔，否则退到前一笔起点；“完整字形”立即结束动画并保留全词。变速只影响后续时间。每笔时长依据字形坐标中的路径长度计算，标准速度以每秒约 2.2 个小写主体高度为初值，短笔至少 350 ms，点笔约 300 ms；同字母抬笔约 220 ms，换字母约 470 ms。实际浏览器播放检查了 `cat`、`book`、`apple`、`yellow`、`playing`，这只是本次技术调参，不代表适合每个孩子。

“看拼写”是独立的次要字母轮播，不冒充书写。点词内字符会在当前词卡中回看该字符，返回后原词进度仍在。独立字母表也使用同一套路径与播放控制。读音、例句和详细释义置于书写区之后；详细内容默认收起。

## 字形与内容边界

52 个大小写字母和撇号、弯撇号、连字符使用同一套 SVG 手写路径，范字、淡色提示、动画和单字母示范一致。四线坐标为上伸／大写线 `20`、小写主体上沿 `48`、基线 `94`、下伸线 `112`。每字由路径控制点计算字宽和 advance，窄字母不被拉宽，播放前定稿排版。路径是本项目原有自绘基础印刷体手写示范，本轮逐字总览检查并修正大写 `J` 的基线；它不是全球或学校唯一笔顺标准，也不是普通字体轮廓描边。笔尖只标当前笔。

英文输入保留大小写及词内撇号、弯撇号、连字符；独立小写 `i` 显示为代词 `I`，其他大小写不暗中改变。前后空白去除，不支持的字符或位置错误的标点明确报错。一次最多 12 个词、总输入 120 字符、每词 32 字符。本轮只支持这些字符组成的词，不提供句子或文章书写。词典查询键不区分大小写并统一两种撇号；未收录词仍能看完整写法，但不编造词义、例句或核验读音，也不写入书架。

本地词库 10,547 条，来自固定版本 ECDICT 的常用纯字母词，并由 English V2 已审定的 48 个儿童词义覆盖同名词。已审定词义优先；扩展词条注明 ECDICT 来源，多义项在详情中展开。浏览器系统语音的音色和离线能力依赖设备。筛选、哈希与许可见 [`SOURCES.md`](../../public/english-study/SOURCES.md)。最近查看最多 24、收藏最多 128，仅记录已收录词，使用独立 `family-games/english-study/v1`；损坏、未来版本或另一页更新的原记录不会被覆盖。

## 本轮验证

- `pnpm exec vitest run tests/english-study.test.ts tests/portfolio-governance.test.ts`：数据、排版、状态、存储和入口检查。
- `pnpm exec playwright test --config playwright.english-study.config.ts`：Chromium/WebKit 的桌面、360/390 手机、768/1024 平板及横竖屏配置；真实指针、触摸、键盘，SVG 笔迹增长、暂停两秒、两个 `p`、完整保留、焦点、缩放、切词和外部请求检查。后台事件在无界面的自动化环境中用 `visibilitychange` 模拟。
- `pnpm run portfolio:check` 与 `pnpm build`。
- 标准速度下实际播放 `cat`、`book`、`apple`、`yellow`、`playing` 至完成；全部 52 个大小写字母有静态总览检查。关键截图、短录屏和手机长词截图位于 [`docs/english-study/evidence-20260924`](../../docs/english-study/evidence-20260924)。

这些检查只验证技术与内容契约，不证明儿童喜好、学习效果或学校认可。
