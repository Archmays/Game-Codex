# 世界盒子四项模型重建

范围：艾莎、圣母教堂主体与圆顶、冰宫原六件及其固定承托、奥古斯都桥。保留三盒、18/16件、拼装顺序自由度、原存档键与玩法。[固定机位前后对照](refine-comparison.html) · [来源说明](refine-sources.md)。

## 实际改动与视觉复查

| 对象 | 正常距离与近景改变 | 侧后方、接口和动作检查 |
|---|---|---|
| 艾莎 | 连续校形的脸颊、下颌、眼眶、鼻梁与口周；嵌入式杏眼；侧扫发束、三股连续交织辫；肩颈、束腰、裙摆和有厚度的披风分别建模 | 修掉黑靴穿裙和披风肩部穿插；保留行走/挥手/施法 clips 与 `elsa_hand`。施法改为向前抬手，移至辫子另一侧，特效跟随误差为0。未新增乘坐玩法。 |
| 圣母教堂 | 重新统一主体/钟形穹顶比例，分层檐口、壁柱、山花、真实凹入门窗、灯笼塔开孔；旧石集中为有组织的墙面石材区 | 四立面成立；主体与圆顶仍为两件。圆顶先装时与承托重叠0.05单位，没有悬空；拼好后旧支撑隐藏。不是精确测绘模型，四角与旧石分布仍有玩具化简化。 |
| 冰宫 | 台阶、开放厅堂、门厅、向心穹肋、后部晶片与细长主尖顶组成整体；六角截面、薄棱、厚门叶与吊灯共享冰晶结构 | 保留左右门轴、吊灯枢轴、原路径与上层承托。删掉重复前框架，穹肋汇合到吊灯位置；侧后方保留开放空间，未用全透明、泛光或飘雪遮盖结构。 |
| 奥古斯都桥 | 连续拱腹/拱上墙、径向拱石、削水桥墩、檐口、玩具栏杆与连续轨道；三个桥孔均为真实开孔 | 整船包络包含轮桨、船舱、烟囱，0.025单位网格扫查无碰撞；车轮最低点1.495、轨面1.508、桥面1.460，轮轨有接触且桥面未遮轨。保留三孔及压缩尺度，不重排城市。 |

至少三轮真实游戏复查后修正：首版头发像梳齿、披风上缘被身体穿出；首版冰晶被平滑法线变成圆管；窗玻璃因挤出面朝向错误被遮住；施法臂原方向与角色朝向相反；冰宫重复穹肋和粗短主尖顶削弱了层级。以上分别修改了网格、发流、挂点、法线、动画方向和结构，并重新导出检查。中性材质对照独立于彩色画面；面数增加不作为视觉通过依据。

第一轮失败的窗洞画面保留为诊断证据。最近观察视角有时裁到建筑尖顶，因此另保留退远机位的侧后方全形视角，以及门打开、施法、走动、挥手和乘员状态截图。它们均来自实际挂载游戏，未以Blender渲染替代。

冰雪盒半球光由3降至1.8、主光3降至2.7、侧光1.8降至0.9；颜色空间、ACES、曝光1.04与阴影设置保留。德累斯顿现有光照保留。雪、冰、皮肤、头发、衣料与木底座使用不同粗糙度/颜色；无新在线资源、压缩解码器、商业模型或生成概念图。

## 资产与保护

独立源：`games/world-in-a-box/blender/refined-models.blend`。显式造型配方：`author_refined.py`；正常两盒导出只通过 `refined_library.py` 导入源资产。源缺失会失败，不回退到旧模型。重导出命令与分组名见游戏README。

正式GLB位于 `public/assets/world-in-a-box/{dresden,frozen}/`；导出manifest记录源库及GLB哈希。18/16根节点、接口、手部/座位节点、门轴、吊灯轴及动画名称通过实际GLB检查。非目标拼件的所有变换后三角形与起点 `58cd16b7` 在0.0001场景单位精度内一致，不依赖导出顶点排序。窗边、大厅、其他游戏和存档实现不改。

车辆回归另发现原有靠岸数值边界：进入0.001纵向对齐区后可能停在5.799…，导致严格到站检查失败。增加一行终点归位和四个近终点反例；保留原0.0001浏览器断言、路线、速度、桥孔和存档。完整横穿含减速/横靠的等待上限单独为14秒，不提高通用9秒UI超时。

## 验证结果

最终数值与同源绑定写入 [验收数据](refine-evidence/acceptance.json)、[资源检查](refine-evidence/assets.json)、[几何检查](refine-evidence/geometry.json)、[性能对照](refine-evidence/performance.json)。

浏览器使用全新隔离上下文，不访问家庭真实存档。键盘从入口使用真实Tab/方向键/Enter，不注入装配状态或强制聚焦；鼠标和模拟触屏分别操作。固定视角/中性材质检查使用只读场景句柄设置检查机位，与玩法验证分开。生产构建另在本地HTTP项目子路径执行，阻断非本地请求并验证重载截图不变。

机器证据覆盖：两盒装配、上层先装、撤销、重置、换盒、刷新恢复和返回；车船、缺桥停车/装桥继续/撤桥退回；三种魔法、雪宝滑行、雪橇/乘员与收桥；冰门、吊灯；窗边开窗/风与基础声音。未重复长时间音频验收。

实际结果：41项单元测试（5个文件）、类型检查与Vite构建通过；德累斯顿7组、冰雪盒8组真实输入/视口流程通过。另通过窗边盒、动作连接、几何通行、生产子路径/故障恢复与阻断外网检查。对照页37张图片载入、14组相机及画布尺寸一致。构建仅有原有大型vendor chunk提示。

## 边界与发布

这些是风格化家庭微缩模型，不是电影级人物或精确建筑复原。没有物理手机/平板、真人儿童偏好或学习效果结论；帧时是本机隔离Chrome结果，模拟触屏不是手机性能证据。技术与视觉审查由Codex完成，不冒称多人或真人认可。

本报告在提交前记录本地结果。推送后另核实Portfolio CI、Pages部署SHA与新鲜浏览器的实际入口/资源；最终发布状态随交付回执记录，不能由push结果推断。到四项重建及必要协调为止，不启动其他角色、建筑或新盒子。
