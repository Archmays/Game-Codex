## B · 玩具简化

城市位置经过简化，距离不按比例。校园在视觉内容中占较大面积，以便操作剖面。河流被拉直，桥孔数量、楼层、尺寸、道路、停靠水域、窗户和室内桌椅均经过简化。桥是固定桥，不能升降。

盒中游览线为原创、非真实公交线路，不使用真实线路号或通勤时间。船道是盒内可逆路线，非真实班次。SLUB 屋面和玻璃顶的展开是玩具剖面示意，真实建筑屋顶不会升降；不宣称精确建筑复原。夜景是观赏灯光，不代表天气、日落或任何人的作息。两地钟以设备提供的同一 UTC 时间计算 IANA 时区，不声称联网校时。

## C · 原创虚构

街屋、面包店门面、长椅背包、自行车组合、背景小屋与绿化是原创生活场景，不代表特定商户、住所、办公室或个人行程。木纹和 Blender 网格均为本项目原创制作；没有使用 AI 建筑图片替代实景。
