# 字阵守城

## 游戏目标
在来路旁部署字核、合字、组词，守住城门。三张可直选地图共 22 波：青岚关保留原一条弯路六波，双岔湾以南北双路分配覆盖，烽台关在八波的最后一波迎接会预告呼援的首领。入口 `?play=hanzi-tower-defense`；第一屏保留战场，顶部可选“新游戏”“继续游戏”或明确“重置进度”。

| 地图 | 稳定入口 | 内容范围 |
| --- | --- | --- |
| 青岚关 | `?play=hanzi-tower-defense&map=qinglan-pass` | 原 6 波，9 核／5 配方／2 共鸣；开局火塔与 5 枚背包材料 |
| 双岔湾 | `?play=hanzi-tower-defense&map=twin-bends` | 双路 8 波，11 核／7 配方／3 共鸣 |
| 烽台关 | `?play=hanzi-tower-defense&map=beacon-keep` | 首领 8 波，11 核／7 配方／3 共鸣 |

两张新图各自固定提供火×3、木×5、氵×2、山×2，其中一枚火在塔位 1；各图资源独立。链接只进入所选图的检查点或固定新局，不重置既有进度。

## 适合对象
可在需要时一起读字、讨论塔位的家庭玩家。界面提供读音、短释义和部件位置；机器检查不证明儿童乐趣或学习效果。

## 玩法说明
点材料或已部署的字核，再点空塔位部署。选两枚字核先看组合预览，再确认；材料点击顺序不限，配方决定规范结构和词序。背包＋背包回背包，背包＋字塔替换该塔；两塔组合明确保留／释放位置，可切换保留哪座来源塔。拖到已占塔位同样先预览、再确认，落点为目标，不吞第三枚材料。上下合成炎，左右合成林／沐；火山、山林保留完整双字和词序。新图另可木＋林→森（上木下林的规范品字结构），森＋林→森林（完整词序）。错误组合不扣材料；选一枚即显示搭配与缺料原因，亮起的搭档可直接选择。

指向、聚焦或点选字塔查看攻击范围，不受合成材料顺序影响。选一枚字核后，指向／聚焦空位可预览部署覆盖，触屏点空位直接部署；部署、合成后保留产物查看。触屏可切换“只看射程”，再点塔查看而不改变选料。显示全部射程默认关闭，仅为本页查看选项，不写存档。范围 SVG 使用真实塔位、`CORES[kind].range` 和地图坐标变换；边界表示寻敌距离，不代表命中后的爆炸／减速扩散。

按本轮补充反馈，青岚关 3／7／8 号塔位移近有效路段，6 号位作相邻避让，编号与存档归属不变；路径、原六波、掉落和塔数值仍保留。相同火塔覆盖路段由约 278／152／187 提高到 388／391／387 地图单位；位置仍有前后路分工，不要求击败数完全相同。几何和同一首波的合法单塔模型对照见 `tools/hanzi-tower-defense/check-placement.ts`，实际小屏目标和真实射程另有浏览器检查。

每波材料袋含火、木、氵、山各一枚和一枚种子变体；五次掉落自动入栏，无容量上限。开局即有可用合成。旧图两条竞争路线为炎＋山林及火山＋林；新图还能用森林＋火山分配覆盖，可混合使用沐。塔位影响路径覆盖，字核决定攻击、射程、溅射和减速。多余背包材料仅可修补本局城门，满血时不消耗，不产生货币或材料回购循环。

波间由玩家启动下一波，没有倒计时；战中可暂停部署。失败可立即重开，配方发现保留。原图约四分钟有效战斗加部署／组合时间；新图模型构筑约 4.6–6.2 分钟有效战斗，实际操作时间另计。没有强制倒计时。烽台首领只在耐久降到 75%／40% 时各预告两秒，随后从身后呼来两只团团怪；最多两次，不免疫某种汉字。

顶部“速度”原生按钮可用 Enter／Space、鼠标点击或触屏点选切换 1×／2×，默认 1×。2× 同步加快怪物移动、攻击冷却及首领呼援等模拟计时，仍以 0.05 秒固定步长运行，伤害、投放与掉落规则不变。暂停、隐藏页及波间不推进；暂停中切速不会恢复战斗。速度只存在本页，切图、明确重置、再守一局或刷新后回到 1×，不写入存档。常规完整通关验证仍按默认 1× 执行，加速另作短时实际输入验证。

第 2 波／第 4 波第三次击败分别额外掉落完整英文核 `volcano`／`mountain forest`，存活波尾同记录保底，每局各一枚。火山对应地貌义，山林只指“山上的树林”；`mountain forest` 是保留空格的完整短语。尚无中文词塔时可保留英文，界面直接显示现有合成配方。

选英文再选塔、先选塔再选英文，或桌面拖到塔上，均先预览再确认；背包完整词核也能先装备。火山获得“回声喷发”：原命中点 0.45 秒后再造成 40% 基础伤害；山林获得“根须蔓延”：留下 2.4 秒区域，每 0.4 秒造成 12% 基础伤害并在区内减速 48%。范围、叠加限制和词义来源见 [STEP3 报告](../../docs/hanzi-tower-defense/step3-report.md)。基础攻击保留，不装备英文也有完成旧六波与新八波的合法构筑。战中可首次装备；波间可卸下或转移以比较同名塔位，暂停不算波间。收回／移动时附件和冷却跟随，回收附带材料先预览并原枚返还英文。

新图第 3 波第 3 次击败额外领取完整 `forest`，波尾同记录保底，每图一枚。森林采用“大片树木生长的地方”义。森每 0.8 秒主箭 30、次箭 18、最多两目标；森林每 0.85 秒主箭 42、次箭各 27.3、最多三目标，forest 共鸣将上限增加到四目标，其他数值不变。主次目标都在真实射程内，按各自到城门的剩余路程、再按 ID 确定，不跨路线比较原 distance。没有溅射、减速、根区或递归分叉；森林的单靶伤害低于森＋林前体合计，收益在受限多目标。新字／配方／forest 均不进入原关奖励序列。

## 涉及知识点
材料和完整字不同：氵标为“非成字部件／三点水”；不将它作为独立整字认读。完整内容有十一条记录和七条配方，原图限定原九条和五条；见 `content.ts`，逐条绑定汉典条目、字形、位置、读音、简义、熟悉词和视觉说明。沐为氵旁木声；水波／藤蔓／熔岩等仅是法术设计，不解释为字源。

## 设备适配
鼠标点击及拖放、触控点选、完整键盘操作共用同一规则。Tab 跨区，材料／塔位／英文区内方向键与 Home/End 快选；Enter／Space 原生确认一次，P 在游戏上下文暂停，Esc 放回选择或取消弹窗。编辑域、输入法组合与浏览器组合键受保护；失焦／取消后不会完成残留拖动。详细约定见 [输入合同](../../docs/input-contract.md)。小屏允许页面自然滚动，字塔保留可操作尺寸。静音和减少动态独立保存；隐藏页面自动暂停并停止声音，回来需主动继续。没有麦克风请求、识别 SDK、录音、账户或网络遥测。

## 当前完成度
三张地图各八塔位，共 22 波；保留三类普通敌人，仅新首领图增加一种有两次预告呼援的首领。新图完整库为 11 字核、7 配方和 3 双语组，旧图锁定 9／5／2。Phaser 表现层使用同一个固定步长战斗模型；路径、投放与检查点按图配置。素材复用已批准的无道路草地背景、火山／山林形态和 Kenney CC0 部件／塔基，新路由模型绘制，规范汉字由真实字体显示。

当前设计见 [STEP4 设计](../../docs/hanzi-tower-defense/step4-design.md)，统一结果与验证边界见 [本次试玩报告](../../docs/step4-playtest-report.md)。历史 [STEP3](../../docs/hanzi-tower-defense/step3-report.md)、[STEP1](../../docs/hanzi-tower-defense/step1-report.md) 及 [热修报告](../../docs/hanzi-tower-defense/step1-hotfix-report.md) 保留。

## 接入方式
`index.ts` 导出标准 `GameDefinition` 及独立 `mountHanziTowerDefense`，沿用 Vite＋TypeScript＋Phaser。当前存档键为 `family-games/hanzi-tower-defense/v3`，按稳定 mapId 保存各图的检查点与发现配方。仅 v3 不存在时，先读取 v2，只有 v2 不存在才读取 v1，并只复制验证合法的旧值；v2／v1 原始字符串保留，旧局映射青岚关，旧波次、实体冷却、英文归属与领取记录延续，不补发已过波次奖励。三个精确键由既有 Vault 登记导出／恢复。

“继续游戏”列出可继续的地图存档；“新游戏”可以直接选任一地图，已有存档会先明确询问是否重置该图。“重置进度”确认后重置所选图波次、材料和配方发现，其他地图与旧原文保留。结果页“再守一局”则延续原有重玩语义，保留已发现的配方。

战中只保存波前经济检查点及非经济性的配方发现；切图会明示未完成波次回滚，返回／刷新重打该波，中文消耗与英文领取／附件一起恢复。波间部署／装备即时保存，切图同步 URL 的 map 并保留返回上下文。坏／未来 v3 优先保护，不用旧值覆盖；每次写入比较已读原始字符串，跨页或 Vault 恢复改写后旧页停止写入，仍可本页游玩。其他游戏存档不读取、不迁移，也不调用全库清空。

## 后续改进建议
以下是已固定方向，本次不实现，也不显示空入口：

- 双语共鸣已实现；下一阶段方向为正确说出两种目标词后短时提高对应塔攻速，须另获明确授权。
- 语音模式须完成明确授权，随开始游戏启动，前台期间持续监听；不逐次点击、不先选塔、不手动切语言。双语词自动匹配塔，同名多塔确定性选择一座就绪塔，去重并受冷却限制。不中断战斗判题，不因环境对话反复暂停；常显监听／静音状态。
- 离开、隐藏、锁屏或静音时停止采集并释放资源；恢复符合已选模式和浏览器授权。处理识别会话中断，不把 `continuous=true` 当永不中断保证；抑制示范音／音效自触发。不储存录音或对话，不将识别命中冒充严格发音评测。云端音频处理必须另行明确授权，不能静默降级。
- 本次不请求麦克风，不添加语音 SDK、模型或后端，也不因未来语音兼容性阻塞交付。
