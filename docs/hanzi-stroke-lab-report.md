## 识别实测

`tools/hanzi-stroke-lab/handwriting-fixtures.mjs` 独立编写36字几何手写轨迹，不从笔顺 JSON、中线或识别模型复制。只将轨迹与修订号送入原 Worker，预期字和样本名不进入引擎。

| 样本 | Top-1 | Top-5 |
| --- | ---: | ---: |
| 36字原始合成书写 | 27/36（75.0%） | 32/36（88.9%） |
| 加偏移、缩放、约4.3°旋转，共144次 | 106/144（73.6%） | 127/144（88.2%） |

原始失败：入（第7）、天、火、井（前10未出现）；旋转的八也降出前5。全部候选/排名保存在 `recognition-results.json`。这些样本可验证真实轨迹计算及抗变换行为，**不代表真人或儿童识别准确率**。候选是建议，用户可撤销/重写/文字查询；不强制选择第一个。

## 专门反思与修正

1. **核心真实性**：识别为真实 WASM 匹配，动画为有方向中线遮罩与原笔画路径；非换皮、iframe、预置候选或整字淡入。
2. **候选可点击性**：发现画布失焦会清掉候选，修正为只取消未完成的笔；候选选择后自然进入笔顺。
3. **异步旧结果**：增加修订号及“仍需识别”状态，取消模型加载期间旧请求；晚字形加载与卸载均失效。
4. **返回生命周期**：销毁 Worker、监听与动画；BFCache 返回重新挂载。历史空查询清理旧字形和读音，防止残留。
5. **可见状态与操作**：待写用虚线，当前用描边及序号；缩略图固定最小尺寸换行，33笔长字能到末笔。列表保存焦点位置，手机画布约294–324 CSS px。
6. **触摸验证**：零时长CDP手势会让随后原生click消失，空HTML复现证实为测试输入时序；改为80ms抬笔时序，未添加“触摸直接触发答案”的旁路。实际移动仍通过原Pointer Events。
7. **边界**：没有新增框架、课程、奖励、评分、账户或跟踪；旧游戏runtime、内容和旧存档键未变。仅真实新增工具导致目录/存档数量断言更新。
