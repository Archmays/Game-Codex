# 3–5 分钟黄金样板规格

状态：`FOUNDATION / NOT IMPLEMENTED`。本规格只定义第一条可玩竖切，不授权完整墨迹森林、正式大规模美术或新 Phaser Scene 实施。

## 要回答的唯一体验问题

在一条 3–5 分钟、最多 12 个已审汉字的体验里，黄小越能否在少量提示下把部件放进真实结构槽位完成第一次施法，并因为一次能力选择和营地永久变化而想再试？

## 范围预算

| 项目 | 上限 |
| --- | --- |
| 英雄 / 同伴 | 1 / 1（墨点精灵） |
| 可玩汉字 | 最多 12 个，独立 manifest |
| 手牌 | 每次 5 张部件牌 |
| 普通战斗 / 小首领 | 2 / 1 |
| 普通怪物类型 | 2 |
| 能力选择 | 1 次三选一 |
| 营地永久修复 | 1 个物件 |
| 目标局长 | 3–5 分钟；首次成功施法尽量 ≤60 秒 |

## 可实现流程与验收点

### 1. 儿童进入路径（0:00–0:15）

大厅卡片进入后，首屏直接看见墨迹森林边缘与字灵营地；主按钮是世界内动作“出发”，不是课程、年级或练习菜单。首次进入最多两次点击开始。家长入口、静音与减少动画位于次级但可发现的位置，不覆盖主行动。

自动验证：路由可进入、主要按钮存在、两步内到达可玩状态。儿童观察：是否把它描述为要去冒险，是否自己找到下一步。

### 2. 字灵营地首屏（0:15–0:30）

画面中央是一个明显褪色/破损、稍后可修复的营地物件；英雄和墨点精灵在可走向森林的路径旁。魔法书图标显示已发现字的视觉收藏，但不显示正确率、错题或课程进度。首屏只保留一个持续目标：“找回一个新字，修好营地灯”。

### 3. 墨点精灵引导（0:30–0:45）

墨点精灵先飞向闪动的部件牌，再飞向对应结构槽；一次短语音/气泡：“把两个字灵放回它们的位置。”若 4 秒无操作，才出现路径脉冲；若孩子已开始操作，提示立即收起。不得弹出长规则页或手指强制跟随。

### 4. 第一场合字战斗（0:45–1:20）

一只低威胁墨团挡住路。战斗区保持世界可见；DOM overlay 显示 5 张大尺寸部件牌与空结构槽。首题使用高熟悉度、两个清晰部件、视觉结构明确的左右或上下结构字。目标不是“选择正确答案”，而是亲手完成空间组合。

### 5. 五张手牌与结构槽位

- 手牌固定为 5 张，至少包含完成目标字所需的所有部件，并包含能形成温和探索但不构成另一个歧义目标的干扰部件。
- 点击部件后，再点击或拖到结构槽均可；手机不要求高精度拖拽。
- 结构槽用轮廓和位置表达左右/上下/包围关系，并有图形标签；不只依赖颜色。
- 已放部件可再次点击撤回；不扣分、不消耗资源。
- 规则层只接收“部件 ID → 槽位 ID”，不依赖精灵坐标或补间完成时刻。

### 6. 第一次成功施法的完整顺序

目标总时长约 1.8–2.6 秒；减少动画模式约 0.5–0.8 秒且不丢信息。

1. 最后一个部件吸附到正确槽位，轻声“咔哒”；两个部件仍清晰可辨。
2. 结构轮廓从外向内收拢，明确表现真实空间关系；不得先瞬间替换成整字。
3. 完整简体汉字稳定出现并朗读一次标准读音。
4. 字旁显示一个熟悉词或短义项，停留到孩子下一步，不作为飘走字幕。
5. 汉字的意义转为原创魔法效果，例如与“木/林”相关的生长效果；效果从字本身发出。
6. 魔法命中墨怪，怪物变淡/散开，世界颜色恢复一小块；避免剧烈闪白和强屏震。
7. 新字以小型书页印记进入本局发现栏。首个成功不被积分、连击或奖励弹窗盖住。

声音层次：吸附、成字、读音、魔法、世界恢复各有职能；控制峰值、可静音、避免同时拥挤。无声音时，轮廓、文字和世界变化仍完整表达结果。

### 7. 无效组合的温和反馈

部件停留 250–400ms 后轻轻回到手牌，槽位短暂描边；墨点精灵说“这个位置还在等另一位字灵”或“换个位置看看”。不出现叉号、扣血、倒计时、嘲笑、`败北`、`做错了` 或 `你还需要练习`。连续两次未成字后，只高亮一个可行槽位；不自动完成整题，除非家长入口主动开启辅助。

### 8. 第二场战斗（1:20–2:05）

使用不同结构类型或同结构的新组合验证迁移，而非重复第一题。怪物的可读行为只改变当前选择，例如遮住一个槽位片刻后立即恢复；不引入额外资源系统。至少一次让孩子在两个都能形成已审汉字的路线中选择，使“选字”带来不同但均安全的魔法效果。

### 9. 一次三选一（2:05–2:25）

三个选项都用图标 + 2–6 字短标签 + 一句可朗读说明，并立即改变小首领战的一项可见行为。例如：

- `生长印`：成字后多修复一格颜色；
- `回声墨`：本战第一次读音可再点一次重听；
- `护字光`：一次无效组合后保留已放对的部件。

不出现稀有度、抽取概率、价格或“最佳”暗示。三项强度接近，选择后在英雄/墨点精灵上产生可见标记。验收不是孩子选了设计者期待的项，而是能指出“我选了哪个/它会怎样”。

### 10. 小首领（2:25–3:35）

一个体型更大但不恐怖的墨怪需要连续完成两个已见结构动作。首领只增加读图变化，不增加新规则：第一字打破墨壳，第二字让完整汉字转为魔法完成驱散。三选一效果必须在这里清楚发生。失败不会清空魔法书或已完成的战斗。

### 11. 营地修复（3:35–4:20）

回营后，新字飞入此前褪色的物件，物件从损坏状态变为可辨识、持续保留的修复状态。变化至少包括形状/功能与颜色两种信号，避免只用粒子。镜头短暂停留，但孩子可以跳过；系统明确说“营地记住了这个字”，不说“完成练习”。

### 12. 魔法书永久保存（4:20–4:40）

魔法书新增该字：字形、读音按钮、熟悉词、意义图、结构拆分和“在营地修复了什么”。存档是带整数版本的本地 JSON，只保存已发现字 ID、营地修复状态、设置和最少试玩事件；载入时校验并在损坏时回退到安全默认。无账号、云同步或儿童姓名字段。

### 13. 结束、失败与撤退

成功界面首要动作是“回营地看看”，次要动作是“下次换一种魔法”；不使用倒计时或即将消失的奖励。失败/撤退界面使用“先回营地，发现都还在”，列出保留的新字和修复，并提供“再试一次 / 回营地”。任何路径都不扣永久资源。

### 14. 减少动画模式

遵从系统 `prefers-reduced-motion` 并在设置提供持久本地开关。关闭相机摇晃、视差、非必要漂浮和密集粒子；用 120–250ms 淡入、描边、静态结构分解和一次轻量状态切换替代。读音、完整字、词义与结果停留时间不缩短。不能因为减少动画而跳过“部件进入真实结构”的教学信息。

### 15. 响应式布局原则

- 手机竖屏：世界占上半部，结构槽居中，5 张手牌以 3+2 或可单排缩放布局置底；关键目标保持 44px 触控面积，不横向溢出。
- 平板横屏：世界/战斗位于左或中央，手牌与短提示在下方，魔法书/设置为边缘按钮；不形成管理仪表盘。
- 桌面：限定最大内容宽度，中央世界不被两侧永久面板包围；鼠标与键盘焦点均可操作，焦点样式可见。
- 三者都让完整字、结构槽和怪物同时可见；打开 DOM 模态层时暂停或门控 Phaser 输入。

### 16. 本地匿名试玩记录

只在本地 `localStorage` 保存以下最小字段，家长可一键清除：

| 字段 | 用途 | 约束 |
| --- | --- | --- |
| `schemaVersion` | 迁移与校验 | 整数 |
| `sessionId` | 区分本机试玩 | 每局随机，不含姓名/设备指纹 |
| `startedAtRelativeMs` | 计算相对时长 | 不保存精确位置或网络信息 |
| `firstActionMs` | 判断入口是否清楚 | 相对值 |
| `firstSpellMs` | 判断 60 秒目标 | 相对值 |
| `invalidPlacementCount` | 发现槽位理解问题 | 总数，不作成绩 |
| `hintLevelMax` | 观察需要多少提示 | `none/pulse/slot` |
| `choiceId` / `choiceDecisionMs` | 判断三选一理解成本 | 仅内部选项 ID |
| `bossOutcome` | 完成/撤退/重试 | 不称“失败者” |
| `campRepairSeenMs` | 是否到达变化画面 | 相对值 |
| `spellbookOpened` | 是否主动查看 | 布尔值 |
| `reducedMotion` / `muted` | 复现设置 | 布尔值 |

不得记录儿童姓名、出生日期、自由文本、语音、照片、按键全文、IP、广告 ID、账号或向网络发送事件。记录只辅助复盘，不能单独推断兴趣或学习。

### 17. 12 个汉字的选择原则

不是先随意列字再补理由。候选字必须同时满足：简体字形与结构清楚；由 2–3 个可辨部件组成；至少覆盖左右、上下和包围等 2–3 类结构；黄小越大概率认识其中 70–80%；新字比例控制在 20–30%；每字有熟悉词、读音、意义图和可转为原创魔法的语义；避免生僻、多音歧义强、字形争议、部件难以独立呈现或需要错误字源故事才能解释的字。12 字整体应让部件有计划地复现，以验证迁移而非记一题一答案。

任何具体 12 字名单必须由 `hanzi-structure-quality` 数据门禁、自动一致性测试和教师/家长逐字适龄审核共同通过后，才能进入 playable manifest。

### 18. 留到完整 Pilot 的内容

完整 8–12 分钟 Pilot 才可讨论第二位英雄、更多营地互动、第三种普通怪物、区域内分支路线、更多能力组合、设置完善和正式音频层。多个区域、开放世界、多货币、装备、宠物、数十战斗、数百能力、账号、云端记录和大规模资产库仍不是 Pilot 自动授权范围。

## 技术分层约束（未来实现时）

- `simulation/` 是规则、RNG、战斗状态与存档真源；给定种子与动作序列必须可复现。
- `content/` 只读可玩 manifest 与关卡配置，不从 382+ 母库运行时随机抽低龄字。
- Phaser Scene 只编排加载、输入桥接和 view 更新；精灵/补间结束不能决定规则结果。
- DOM overlay 负责手牌文字、魔法书、设置、家长区和可访问性；模态层打开时门控游戏输入。
- 资产通过稳定 manifest key 引用；本阶段不生产正式资产。
