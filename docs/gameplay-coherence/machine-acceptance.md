# Independent Machine Acceptance

The same final candidate was assessed through two separate evidence lenses after implementation. Neither review is a child playtest.

## Review A — gameplay and product coherence

Verdict: **ACCEPTED_MACHINE**.

- P0: Equation has one child-facing home, Math World → Slider; Classic contains only the three world products.
- P0: Equation returns to Math World and restores a valid saved level while keeping the 200-level S runtime intact.
- P1: Math direct load, refresh, back/forward, station return, and focus restoration are coherent.
- P1: Array is a responsive causal workbench; Clock, Array, and Target keep action focus through rerenders.
- P2: seven bounded clusters are closed: Classic backup copy, Slider world language/re-entry, calm Math continuation, Array grouping, Clock focus, Target focus/arrival feedback, and lifecycle claim boundaries.
- Browser evidence covers 360, 390, 768, 1024, 1366, 1440, and 1920 widths, pointer/touch/keyboard, zoom, hit testing, scrolling, long-session transitions, and affected visual baselines.

Review A accepts interface coherence and operability only. It does not claim real-child fun, independent re-entry, retention, or learning effectiveness.

## Review B — learning and engineering integrity

Verdict: **ACCEPTED_MACHINE**.

- Every nested station exposes separate mount definition, runtime owner, host product/world, quality profile, runtime saves, host saves, and compatibility surface truth.
- Slider remains owned by `equation-slider`, uses `s-equation-release`, and retains `family-games/equation-slider` even though Math World is its host.
- The empty, auditable Classic exception registry and permanent checker reject an unapproved nested-module card; unit evidence also proves an explicit exception path is reviewable.
- The current truth is 3 top-level products, 3 Classic cards, 9 mount definitions, 11 world modules, 39 play surfaces, 5 primaries, and 37 save keys.
- Frozen prior-cycle evidence remains historical 4-product/40-surface evidence and is not rewritten as current truth.
- Equation generation, solver, hints, IDs, legacy migration, save restoration, release behavior, and UI-only cross-chapter play all pass their affected gates.

Review B accepts declared ownership, preservation, deterministic behavior, and machine-verifiable learning loops only. It does not claim mastery or educational outcomes.

## Reconciliation

Both reviews agree that all scoped P0/P1 and seven P2 clusters are closed without deleting a mount definition, changing a save namespace, rewriting historical evidence, or expanding Hanzi/English game-content scope. Natural-use Observation remains `ACTIVE`; real-child validation remains `NOT_PERFORMED_AND_NOT_CLAIMED`.
