# STEP 05 Post-First-Use Decision

## Decision

`PROMOTE_TO_PRIVATE_WORLD_ENTRY_AFTER_CHANGED_ONLY_FIX`

Child value: the completed, comfortable one-run evidence and immediate replay request justify giving the short Hanzi-magic adventure a stable place to return to without surrounding it with an adult catalogue.

Hanzi-learning value: the candidate preserves the accepted sequence `明 → 花 → 林 → 星`, where structure placement forms the character and the character changes the world. No new character route is inferred from one first use.

Automatic validation path: frozen content identities, phase-explicit voice tests, save/world projection tests, route tests, privacy scans, and browser flows.

Human validation path: a parent changed-only review of evidence semantics, audio repair, world shell, and affected navigation. A separate real second-use check is available only if the parent explicitly authorizes it.

## Changed-only scope

Allowed:

- repair ordinary voice replay so only an explicitly formed character can be spoken;
- split observer reach/notice and replay intent/request/action semantics;
- expose existing permanent state in a private world route;
- keep the classic ten-game hub as a secondary “游戏百宝箱” route;
- add return-to-world navigation and a parent review gate.

Frozen:

- 12-character manifest and first-run four-character order;
- encounters, hands, difficulty, three abilities, two boss phases;
- Theme C, camp repair, spellbook, and save schema/key;
- default `/` classic hub and all unrelated games.

Not authorized: remaining-eight route, enclosure gameplay, another hero/monster/boss, currency, art pipeline, default-world promotion, full Ink Forest, or learning claims.
